# 🌟 STAR 复盘 + 沉淀 / SOP / 赋能

## 一、STAR 复盘（这道题你怎么做出来的）

**S（情境）**
字节 FDE 08 题：给虚构品牌「澄初」做商品智能导购助手。要给到**能跑的原型 + 可讲清的方案**，
核心不是"会聊天"，而是"**负责**"——不编造价格/政策、硬边界不透支，替顾客做对的选择。

**T（任务）**
同时满足两个看似冲突的目标：
1. **效果**：真的能"先了解需求再给选择"，推荐要贴合（肤质 × 目的 × 预算）。
2. **信任/合规**：10 条可检查行为全过（价格准、政策不编造、敏感/医疗/旅行边界、注入防护、追问克制）。

**A（行动）**
- 定主线：**信任主线** = 客需匹配 × 预算匹配 × 信任；一切决策围绕它，凡不服务它的砍掉。
- 定分工：**LLM 只翻译、代码做决策**。把「该推荐哪款 / 价是多少 / 合不合规 / 要不要升级」这件事
  从概率模型里**抽出来**，放进确定性规则层（`rules.py`），可复算、可单测。
- 做**单一事实源** `brand_kb.py`：所有 SKU/价格/组合/政策/边界集中一处，杜绝别处硬编码。
- 用**关键词检测 + 优先级路由 + 状态机**搞定"意图"（`detect→route`），再用 `decide→render` 出决策与话术，
  10 个状态覆盖正常到红线。
- 关键攻坚：**P201（8% 果酸）前置确认**、**旅行分装只绑定"出行/分装"场景**、**子集和价格校验**（388=P101+P203 这类非手动组合）。
- 用「**决策透视面板**」把规则层变成可演示的内核，面试官一眼看懂。

**R（结果）**
- 离线 16 场景全绿；BC-1~10 全绿（含子集和价格、无 P301 泄漏、追问≤2、注入拒绝）。
- HTTP /api/health、/api/trace、/api/chat、index 全部连通；无 key 也能跑。
- 把一道"聊天题"做成"**可复现、可断言、可离线**"的工程题——这正是 FDE 想要的「把 AI 变成可用、可信的东西」。

## 二、沉淀 / SOP（下次直接复用）

### SOP：如何做一个"可复现、不乱编"的 AI 导购/决策代理
1. **先定信任主线**（这家公司最怕什么？价格乱、承诺虚、越权、泄露）→ 由此定 3 条铁律。
2. **分离"事实"与"话术"**：事实表（SKU/价格/组合/边界/政策）成为**单一事实源**，代码只从这读。
3. **把决策从 LLM 里拿出来**：哪些是"必须对"的（价格、合规、升级、安全）→ 确定性规则；哪些是"可以自然"的（语气）→ LLM。
4. **给"必须对"的事做白名单**：价格 = 事实价 ∪ 子集和；政策 = 未提供就"去问/确认"；高危 = 前置确认。
5. **一切可断言**：把 BC 写成自动测试。加"**反向断言**"（如"非旅行不得提 P301"）防止漏。
6. **抗风险设计**：没有 key / 没网也能跑（离线兜底），现场永远稳。
7. **可视化能力**：加一个"决策透视"，把黑盒变白盒，讲起来一张口就有料。

### 可迁移的清单（任何"企业 AI 助手"都能套）
| 场景 | 决策放哪 | 不变量 |
|---|---|---|
| 价格 | 代码 + 白名单 | 事实价 ∪ 子集和 |
| 促销/退换/渠道 | 代码 | 未提供 → 去确认，不编造 |
| 敏感/医疗/风险 | 代码 | 边界判断不进 LLM |
| 意图抽取 | LLM | 只抽槽，不决策 |
| 措辞 | LLM | 严格校验后回退 |

## 三、赋能（讲给团队/复盘会的一句话）

> 别把"能不能编出漂亮回答"当能力，把"**能不能负责**"当能力。
> 这次最大的收获：把**确定性**从**概率模型**里抠出来，让 AI 助手**又自然、又可信、还能被测试**。

## 四、已知局限 & 下一步（诚实清单，被追问也能接）
- 关键词意图在**同义/口语**上会漏（如"来点清爽的"）——已用 LLM 意图抽取补一部分，但仍可作为优化点。
- 预算只做**超支警示**，未做「在预算内重新精算到 1 件」的主动降配（可加）。
- 未接真实商品库 / 订单 / 库存——演示为手工事实表，量产要换数据源并跑同样的白名单。
- 组合策略目前是**硬编码 2 组**，可升级为"按事实表动态求≤N件最优组合"。
