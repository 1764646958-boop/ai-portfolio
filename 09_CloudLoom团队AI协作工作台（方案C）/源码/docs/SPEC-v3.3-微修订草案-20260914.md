# S4.1 变更记录（2026-09-14，负责人决策 A1 / B3 / C1 与会话实测）

> 本节记录 S4.1 对既有决策条目的**正式变更**，与上文「微修订 1–4」同源同权；确认后一并并入 v3.3 正文。

## 修订 5：D15「每日 09:00 晨报」→「每周一 09:00 周报（含复盘）」
- **原文**（D15）：每日 09:00 晨报（LLM 作业）；另有独立「周复盘」周一 10:00。
- **修订为**：晨报（每日）→ **周报 `0 9 * * 1`**（提示词改输出【上周完成/阻塞/风险/本周计划/待拍板】+【本周花费】）；**周报保留 AI 版**（要判断与建议，不做纯脚本版）；原「周复盘」作业**并入**周报，独立作业删除。
- **同期新增**：每日 `0 6 * * *` **0-token 数据快照**（`ops/digest.py`，脚本作业，不调 LLM，产出 `~/team-files/系统通知/快照-YYYYMMDD.md`）。
- **效果**：LLM 例行作业 **15 次/周 → 1 次/周（-93%）**；实测一次周报 ≈ **$0.00953（¥0.069）**，14 次上游调用。
- **依据**：S4.1 C1 实测 + 负责人 2026-09-14 决策 A1 / C1。

## 修订 6：D21「画像每日 cron」→「画像按需触发」
- **原文**（D21）：画像作业每日 06:00 定时。
- **修订为**：**取消定时**（作业已删除，无 `next_run`），改为按需：`bash /opt/team-console/ops/run-job.sh profile` 一条命令生成画像 JSON 并落 `~/team-files/系统通知/画像/`；`/api/profiles` 按目录内 **mtime 最新**读取（产物命名与读取双双加固）。
- **依据**：S4.1 C1-④ 实测（实发 2m01s）+ 负责人 2026-09-14 决策 B3。

## 修订 7：新增 C3 上下文窗口策略条款
- 发往网关的历史默认**只保留最近 12 轮**（`CHAT_HISTORY_MAX_ROUNDS` 可配）+ 一条「更早对话已省略」系统说明；
- **必须保留**：任务上下文注入、D35 修正记录注入、@Agent 拉入的 `【上下文提示】` 片段（实现为标记白名单，实测不被裁剪）；
- 可选摘要模式默认**关**：`CHAT_SUMMARY_ENABLED=1` 时对溢出部分摘要并按 (conversation, agent) 缓存。
- **依据**：S4.1 C3 实测（30 轮省 5.7%、120 轮省 26.8%；Agent 固定系统提示词约 17.4k tokens 为成本主项）。

## 修订 8：新增 C2 用量记账 / C6-5 登出吊销（加法条款）
- **用量记账**：新增 `usage_log` 表与 `server/src/usage.js` 单一记账点，覆盖 `/api/chat`（非流式 + SSE 两路）、任务中心、@Agent 提及、看板触发；单价常量在 `config.js` 可配；**`est_cost` 为上界估算**（输入 token 未拆分缓存命中部分，缓存命中单价为输入的 1/50）。
- **登出吊销**：`users.token_version`（默认 1）+ JWT `tv` 声明；**登出即 +1**，该用户所有旧 Cookie 立即失效（服务端吊销，非仅清 Cookie）。
- **依据**：S4.1 C2 / C6-5 实测。
