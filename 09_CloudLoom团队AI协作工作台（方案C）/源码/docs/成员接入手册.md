## 一、开始之前：三件先知道的事

1. **工作台只有一个入口。** 聊天、看板、任务、画像、资料库、记忆都在同一个网址里，
   不需要再装别的软件（SPEC D29「入口唯一」）。
2. **Agent 不是「在线的同事」，是「按需唤醒的助手」。** 一个 Agent 没人用的时候是休眠的，
   你一发消息它会自动被唤醒，第一次可能要等几十秒。这是省服务器资源的正常设计，不是故障。
3. **涉及钱、对外承诺、删数据的指令，系统会让你确认一次。** 这是刻意设计的「防呆」，
   不是卡你（详见第十一章）。

## 二、怎么访问工作台

### 2.1 网址

```
https://<域名>/
```

这是**当前的降级访问路径**：因为域名备案还没就绪，暂时用服务器 IP + 自签名证书顶着。

- 请务必用 **https://** 开头（服务器只在 443 端口提供页面）。
- 用浏览器打开这个地址会**自动跳到登录页**；登录后进入聊天页。
- 手机和电脑都可以直接打开，界面会自动适配（窄屏时左侧会话栏收成抽屉，Tab 移到底部）。

### 2.2 浏览器提示「证书不受信任」怎么办

这是**预期现象**，因为现在是自签名证书，不是权威机构签发的正式证书。放心继续访问即可：

- **Chrome / Edge**：点页面上的「高级」→ 再点「继续前往 <域名>（不安全）」。
- **Firefox**：点「高级」→「接受风险并继续」。
- **Safari（Mac）**：点「显示详细信息」→「访问此网站」。
- 如果连「继续前往」都没有，说明站点被浏览器策略拦截，请联系管理员处理。

> 注意：因为证书不受信任，浏览器不会把当前页面当成「安全环境」，
> 因此**「添加到主屏幕（PWA）」和「桌面通知弹窗」在这条路径上可能无法启用**。
> 顶栏的 🔔 站内提醒不受影响，照常可用。等正式域名上线后这两项会自动恢复（SPEC D13）。

### 2.3 手机上怎么用

- 直接用手机浏览器打开 `https://<域名>/`，按 2.2 的方式跳过证书提示即可。
- 因为证书问题，「添加到主屏幕」暂时可能失败；正式域名上线后再做这一步体验最好。
- 手机上 Tab 在屏幕底部，点左下角 ☰ 或者直接点底部 Tab 切换。

### 2.4 什么时候会有好看的域名

`<域名>` 已经解析到这台服务器，但**备案还没批下来**。境内服务器的未备案域名
不能对外提供 80/443 服务，所以现在只能先用 IP。备案通过后：

- 网址会变成 `https://<域名>/`，浏览器不再有任何证书警告；
- 桌面通知、添加到主屏幕（PWA）会一并解锁。

以上是管理员侧的事情，成员只需要知道「网址将来会变」，到时以管理员通知为准。

## 三、注册、登录、退出

### 3.1 注册（新成员第一次用）

1. 打开 `https://<域名>/`（域名备案完成后开放，开放时间以群通知为准），进入登录页。
2. 在登录页顶部把「登录 / 注册」切换到 **注册**。
3. 填写三个输入框：
   - **用户名**（必填）：2 到 32 位，只能使用字母、数字、下划线 `_`、点 `.`、连字符 `-`；
   - **显示名**（可选）：填你希望大家看到的名字（比如「小张」），留空则默认与用户名相同（最长 32 字）；
   - **密码**（必填）：至少 6 位。
4. 点「注册」。

注册结果分两种情况，这是**设计如此**（SPEC D7「管理员邀请制」）：

- **你是团队第一个注册的人** → 页面提示「首个账号，已成为管理员」，并**直接登录**进入工作台；
- **你之后注册** → 页面提示「注册成功，待管理员批准后可登录」，此时账号处于「待批准」状态，
  直接去登录会提示「账号待管理员批准」。

> **管理员批准（2026-09-14 更新）**：管理员登录后进入「设置 → 成员管理」区块，点「批准/启用」即可
> （该区块仅管理员可见）；批准后成员即可登录。原「界面暂无批准按钮、需口头通知」的说明已失效，本次修正。

### 3.2 登录

1. 打开网址 → 登录页，保持「登录」模式。
2. 填**用户名 + 密码**，点「登录」。
3. 常见的失败提示与含义：
   - 「用户名或密码错误」：账号或密码打错了；
   - 「账号待管理员批准」：注册成功了但还没被批准（见 3.1）；
   - 「账号已停用」：账号被管理员停用了，需要联系管理员。

登录成功后，浏览器会收到一个 7 天有效的登录凭证（存在浏览器的 httpOnly Cookie 里）。
你**不需要、也不应该**手工记录或转存任何密钥——前端全程不接触密钥，这是系统的设计红线。

### 3.3 退出登录

有两个入口，效果一样：

- **电脑端**：顶栏最右侧的「退出」（窄屏手机上这个按钮会隐藏）；
- **任意设备**：底部/顶部「设置」Tab →「会话」区块 →「退出登录」按钮。

退出会清除浏览器的登录凭证。之后要重新输用户名密码才能进来。

### 3.4 登录态能保持多久

登录凭证有效期 **7 天**。7 天内刷新页面、关闭浏览器再打开，都不用重新登录；
超过 7 天需要重新登录。如果你换了账号登录（退出后用别人的账号登录），
通知的「未读基线」会自动重置，不会把上一个账号的通知串给你。

## 四、界面总览

登录后是一个「顶栏 + 左栏 + 主区」的布局（手机上是「顶栏 + 抽屉 + 底部 Tab」）：

- **顶栏**：左边是 CloudLoom 标识，中间是 7 个 Tab，中间偏右是 🔔 通知铃铛，最右是你的显示名和「退出」。
- **左栏（仅聊天 Tab 有意义）**：上面是「团队交流」会话列表（含未读红点），下面是「团队 Agent」列表（含就绪数量）。
- **主区**：当前 Tab 的内容。
- **🔔 通知铃铛**：显示系统通知（每天的晨报、周复盘、画像等定时产物的落盘提醒），
  后台每 4 秒拉一次；有新文件时数字角标会 +1，可以点「清空」清掉角标。
  点开某条通知只显示文件名和一点预览，完整文件在服务器的 `~/team-files/系统通知/` 目录里。

## 五、七个 Tab 逐个说

顶栏从左到右依次是：**聊天 ｜ 看板 ｜ 任务 ｜ 画像 ｜ 资料库 ｜ 记忆 ｜ 设置**。

### 5.1 聊天（Tab 1）

聊天 Tab 有两种模式，共用同一个消息气泡样式。

**（A）会话模式（默认）——和同事聊天、把 Agent 拉进群**

- 左栏「团队交流」列出你参与的所有会话，带未读红点；有群聊会标一个「群」字。
- **新建会话**：点「+ 新建」→ 勾选成员（勾 1 人 = 私聊，勾多人 = 群聊，可填群名）→ 创建。
  私聊会自动去重（你和同一个人不会出现两个私聊窗口）。
- **发消息**：输入框打字，按 **Enter 发送**（要换行用 Shift + Enter）。
- **发附件**：点 📎 选文件（单文件 ≤10MB）。附件会先进入「资料库」，消息里会自动多出一行
  「📎 文件名」。超过 10MB 请改用资料库的「添加链接」走网盘（D14）。
- **@ 拉 Agent**：输入 `@` 会弹出 Agent 选择器，详见第六章。
- **撤回**：自己发过的消息，5 分钟内气泡下方会出现「撤回」，详见第七章。
- **成员之间聊天不消耗 AI**，只有 @ 了 Agent 才会真的去调用 AI。
- 消息每 4 秒自动同步一次，所以基本是准实时的；刷新页面历史不会丢。

**（B）Agent 直聊模式——和某个 Agent 一对一连续对话**

- 在左栏「团队 Agent」区点某个 Agent 就进入直聊（标题旁会有紫标的提示，如「Agent 直聊」）。
- 这里是**流式输出**（回答一个字一个字蹦出来），并且会显示 Agent 当前状态：
  「已就绪」或「休眠中（发送即唤醒）」。
- **懒启动**：如果 Agent 在休眠，发送后顶部会显示「正在唤醒 xxx…」，唤醒上限 60 秒；
  唤醒成功再回复。启动失败会明确报错「Agent 启动失败，请管理员检查」，不会假装在思考。
- 直聊历史保存在**你自己的浏览器本地**（IndexedDB），换电脑/换浏览器看不到。
- **直聊模式不支持发附件**，会提示「Agent 直聊暂不支持附件，请在会话中上传」。
- 想回到会话模式，点右上角「← 返回会话」。

### 5.2 看板（Tab 2）

共享看板，是**只读展示**：卡片按状态分列（待办 / 进行中 / 阻塞 / 待复核 / 已完成），
每 8 秒自动刷新一次，顶部显示卡片总数和最后更新时间。

- **看卡片详情**：点任意卡片，弹出详情（标题、状态、负责人、优先级、正文、结果、评论、各阶段时间）。
- **只看有问题的**：勾选右上角「仅看阻塞」。
- **手动刷新**：点「刷新」。
- **怎么改看板？** 看板**不能直接拖拽或编辑**（这是刻意的设计：前端只读，写操作统一交给 Agent）。
  请用页面顶部的「**对看板下指令**」区域：
  1. 在下拉框选一个 Agent（默认是「值班 Agent」）；
  2. 用自然语言写清要做什么（例如「给 xx 卡片加一条评论：……」「新建卡片：……」）；
  3. 点「下发指令」。Agent 执行需要数十秒到几分钟，**期间请勿关闭页面**；
  4. 执行结果会显示在下方灰框里，看板随后自动刷新。

### 5.3 任务（Tab 3）

办公任务中心，是这个工作台最核心的功能，单独在第八章详细讲。

### 5.4 画像（Tab 4）

- 展示系统每天定时生成的「成员画像」JSON 文件（由值班 Agent 在每天 06:00 生成）。
- **可见范围由服务器控制**：普通成员**只能看到属于自己的条目**，管理员能看到全部。
  前端不做也不该做这层裁剪，所以你搜不到别人的画像是正常的，不是加载失败。
- 页面上会显示画像文件的时间；如果某天没有内容，可能是当天还未到生成时间，或那天的数据源为空。

### 5.5 资料库（Tab 5）

团队共享的文件 + 链接清单，聊天里的附件也汇总在这里。

- **上传文件**：先在右上角填「分类」（默认「资料库」，可以自己写新分类，比如「程序」「美术」），
  再点「上传文件」选文件。**单个文件上限 10MB**，超过会被直接拒绝并提示走网盘。
- **添加链接（大文件走这条）**：点「添加链接」→ 填名称、`http/https` 开头的链接、分类 → 「保存」。
  SPEC D14 规定：超过 10MB 的美术等大文件放网盘，系统里只存链接。
- **列表字段**：名称、类型（文件 / 链接）、分类、大小、上传者、时间。
- **打开/下载**：链接条目点「打开」（新窗口跳转）；文件条目点「下载」。
- **搜索筛选**：按名称搜索 + 按类型筛选 + 按分类筛选 + 「刷新」。
- **删除**：只有**管理员**能看到「删除」按钮。删除会**同时把服务器上的文件删掉，不可恢复**，
  操作前有二次确认。

### 5.6 记忆（Tab 6）

团队共享记忆库，单独在第九章详细讲。

### 5.7 设置（Tab 7）

设置 Tab 从上到下分三块：

**（1）个人信息**
- 显示头像占位（取显示名首字）、你的显示名和用户名、角色（管理员 / 成员）。
- 「显示名」可以改（最长 32 字），改完点「保存」。

**（2）通知**
- 「已开启 / 已关闭」按钮：切换桌面通知开关（**保存在服务器上**，换浏览器也生效）。
- 「申请 / 检查权限」：向浏览器申请通知权限。如果之前误点了「拒绝」，需要到浏览器地址栏的
  站点设置里手动重新允许。
- 「发送测试通知」：验证通知链路是否真的能弹出来。
- 下方显示：轮询间隔（4 秒）、最近一次轮询时间、未读站内提醒条数、「清空」。
- **iOS 用户特别注意**：iPhone/iPad 上必须先「添加到主屏幕」，再从主屏图标打开，
  通知权限才可用（这是苹果的限制，不是工作台的问题）。

**（3）Agent 工坊**
- 所有成员都能看到 Agent 卡片：显示名、id、端口、运行状态（绿点=运行中）、是否预设、是否已停用。
- **普通成员只能看**，页面会提示「仅管理员可新建/编辑/停用」。
- 管理员可以：新建 Agent、编辑、停用/启用、删除（4 个预设 Agent 只能停用，不能删除）。

**（4）会话**
- 「退出登录」按钮，等同于顶栏的「退出」。

## 六、@Agent：把 Agent 拉进来说一句话

### 6.1 怎么 @

1. 在**会话模式**（不是 Agent 直聊模式）的输入框里输入 `@`，会弹出一个 Agent 选择器；
2. 在列表里点一下要拉的 Agent，输入框里就会补上 `@它的id`；
3. 继续把你的问题写完，按 Enter 发送。

也可以不点选择器，直接手打。以下三种写法都能被识别到同一个 Agent（匹配 id、显示名、
或去掉结尾「Agent」的显示名）：

```
@cehua      （用 id）
@策划Agent   （用显示名）
@策划        （显示名去掉 Agent 后缀）
```

> 已停用的 Agent 不会出现在选择器里，@ 了也不会被拉起。

### 6.2 拉进来之后会发生什么（答完即走）

- 被 @ 的 Agent 会在会话里**回复一条消息**，气泡上标着紫色「Agent」字样，然后**就离开了**。
  它不会继续参与你们之后的对话，也不会盯着这个会话——这就是设计上的「临时咨询，答完即走」。
- **它能看到什么**：该会话**最近 24 小时内、最多 20 条**消息的片段，只作为背景参考；
  它只回答你当前这一句。所以上下文很长的讨论，最好把问题问得完整一点。
- **需要它看完整会话**：按设计需要显式「共享完整会话」（会有二次确认）。
  当前版本的界面上没有这个按钮，以实际界面为准。
- 一次消息里 @ 多个 Agent，会分别触发，各自回一条。
- Agent 回复偏慢是正常的：先唤醒（最多 60 秒）+ 再生成。
- 注意 Agent 的回复是**会话消息**，该会话的所有成员都能看到，别在不相关的群里 @ 它问私密问题。

### 6.3 直聊和 @ 拉入的区别

| | Agent 直聊（左栏点 Agent） | 会话里 @Agent |
|---|---|---|
| 上下文 | 你和它的完整聊天历史（存在你本机） | 只是群里的一个片段，答完即走 |
| 输出 | 流式（一个字一个字） | 一次性回复一条消息 |
| 同事能否看到 | 不能，只有你自己 | 能，会话里所有人可见 |
| 附件 | 不支持 | 支持（先进入资料库） |

## 七、撤回消息

撤回的规则以服务器代码为准，**和微信不一样，不要凭印象操作**。三条硬规则：

1. **只有发送者本人能撤回**——别人发的消息你撤不了。
2. **只有 5 分钟以内能撤回**，超过 5 分钟系统会直接拒绝并提示「超过 5 分钟…」，**不能延长时间**。
3. **每条消息只能撤回一次**，撤回过的不能再撤。

操作方式：在聊天里找到你刚发的那条消息，把鼠标移到时间那一行，**5 分钟内会出现「撤回」两个字**，
点一下即可。看不到「撤回」按钮，说明已经超时、或者那条不是你发的。

撤回之后：

- 消息气泡会变成灰底斜体的「消息已撤回」，内容被清空，**所有人（包括对方）看到的都是这个状态**；
- **Agent 发来的消息不能撤回**（不是「你发的」）；
- 撤回**不是删除**：聊天记录本身按 SPEC D4 是永久保留的，只是不再展示内容。
  所以别把撤回当成「抹掉证据」，重要内容发之前想清楚。

## 八、任务中心（最常用的功能，重点看）

### 8.1 怎么发起一个任务

1. 切到「任务」Tab，点「**+ 发起任务**」展开表单；
2. **任务标题**（必填）：一句话说清要什么，例如「第三章剧情分支草案」；
3. **选择执行 Agent**（必填）：下拉里是所有 Agent，选一个职责匹配的；
4. **任务描述**（必填）：写清**要交付什么、口径、格式要求**。这段文字会原样交给 Agent，
   写得越具体，产物越可用；
5. **@ 引用文件（资料库）**：左边列表里勾选资料库中的文件。
   勾选后，Agent 执行时能看到文件的名称、分类、路径；对体积较小的文本类文件
   还会带上开头一段内容摘要（大文件、二进制文件只给路径，读不出内容）；
6. **@ 引用记忆**：右边搜索框输入关键词，勾选要引用的记忆条目。搜索结果是按你的权限过滤过的；
7. **需要人工审批（D36）**：一般**不用手动勾**——只要描述或引用内容里出现敏感词，系统会自动强制人审
   （见第十一章）。
8. **产物记忆可见性**：选「团队 / 仅自己 / 指定成员」，决定任务完成后自动沉淀的那条记忆谁能看。
   **注意**：当前表单没有提供「选择哪几位成员」的入口，所以选「指定成员」会提交失败
  （服务器会提示需至少指定 1 位成员）。在补上入口之前，请先用「团队」或「仅自己」，
   产物记忆生成后可以到记忆 Tab 里编辑它的可见范围（作者或管理员可改）。
9. 点「**提交任务**」。提交后如果命中了敏感词，表单下方会提示
   「已按 D36 强制人审（命中：xxx），完成后需审批」。

### 8.2 五种任务状态的含义

| 状态 | 界面文字 | 含义 | 你该做什么 |
|---|---|---|---|
| `queued` | 排队中 | 已入队，等这个 Agent 空出来 | 等待；详情里会显示「前面还有 N 人」 |
| `running` | 执行中 | Agent 正在干活（可能带工具调用、写文件） | 等待，别重复提交 |
| `waiting_approval` | 待审批 | 干完了，但触发了人审，必须有人点头才算完成 | 去详情页填审批意见并选择通过/修改/打回 |
| `done` | 已完成 | 产物已登记，并已自动沉淀一条结论记忆 | 去产物区下载 |
| `failed` | 失败 | 没做成（或被你取消/被驳回） | 看错误信息；失败**不会**沉淀记忆 |

状态是**彩色徽标**显示的；列表顶部还可以按状态筛选，并且会显示「N 项待你审批」。

### 8.3 连发两个任务会怎样（队列）

**同一个 Agent 同时只跑一个任务**，其余排队——这是 SPEC D11 的硬规则，避免同一个人格被并发撕扯。
所以你连发两个给同一个 Agent，第二个会显示「排队中」，详情里会出现「**前面还有 N 人**」
（N = 正在跑的那个 + 排在你前面的）。想快点出结果，就换一个 Agent 提交，或者等第一个跑完。

### 8.4 产物在哪、怎么看、怎么下载

- Agent 被要求把交付物写到服务器的 `~/team-files/产出/<任务ID>/` 目录下（支持子目录）。
  任务完成后系统**立即扫描**这个目录，把文件登记出来。
- 在任务详情页往下找「**产物**」区，每条产物有四个操作：
  - **预览**：读取文件内容的前 20000 字直接显示。文本类文件最好用；
    图片、Office 文档这类二进制文件预览会是乱码或提示读取失败，请直接下载；
  - **下载**：浏览器直接下载该文件；
  - **分享到会话**：点开后列出你参与的所有会话，点其中一个，就会把
    「【任务产物分享】+ 文件名 + 下载地址」作为一条消息发进那个会话，同事收到后点开即可下载（需登录）；
  - **存资料库**：把这条产物的下载地址登记成「资料库」里的一条链接，同时把地址复制到你的剪贴板，
    方便以后长期查找。
- 两个分享入口怎么选：想让同事**立刻看到**，用「分享到会话」；想让它**沉淀下来以后还能找到**，
  用「存资料库」。
- 产物下载地址**需要登录状态**才能打开，所以把链接直接发给团队外面的人是打不开的，这是符合预期的。

### 8.5 审批区怎么用

只有**「待审批」状态**、并且**你是这个任务的创建者或是管理员**时，详情页才会出现审批区（「待人审（D36）」）。

- 「审批意见」是**必填**的，不填点按钮会提示「审批意见（note）必填」；
- 三个按钮的作用完全不同：

| 按钮 | 动作 | 结果 |
|---|---|---|
| 通过 | approve | 任务变「已完成」；同时把结论沉淀成一条记忆（你的审批意见会写进这条记忆） |
| 修改 | modify | 任务**回到「排队中」重新执行**，带着你的意见一起给 Agent 看 |
| 打回 | reject | 任务变「失败」，错误原因是「审批驳回：你的意见」 |

- **「修改」还有一个额外好处**：你的意见会作为「修正记录」存下来。这个 Agent **近 30 天内**
  被记录的最多 **5 条**修正记录，会在**下一次同类任务**执行前自动注入它的上下文（D35）——
  也就是「上次被否掉的点，这次它先看到」。所以写审批意见时尽量说清「哪里不行、应该怎样」。

### 8.6 取消任务

- 详情页底部有「取消任务」按钮，只在**排队中 / 执行中 / 待审批**三种状态出现；
- 只有**任务创建者或管理员**能取消；
- 取消后任务状态是「失败」，原因是「已由 xxx 取消」；
- 已经「已完成」或「失败」的任务不能再取消。

### 8.7 失败、超时、低置信是怎么处理的

- **Agent 明确说做不了** → 任务直接失败，错误信息里带原因（「Agent 声明无法完成：…」），**不沉淀记忆**；
- **Agent 说「低置信」**（自己没把握）→ 后端会自动请**值班 Agent（zhiban）复核**：
  复核不通过 → 任务失败；复核服务本身不可用 → 保守处理，**自动升级为「待审批」**交给人判断；
- **执行超时**（默认 10 分钟没返回）→ 任务失败，提示建议拆分任务或稍后重试；
- **服务器重启导致执行中断** → 系统会自动把中断的任务重新排回队列，**不需要人工干预**，
  你看到状态从「执行中」变回「排队中」是正常的自愈行为。

## 九、记忆库

记忆库是团队的「共同脑子」：重要的决策、口径、结论沉淀在这里，下次发起任务时可以 @ 引用，
Agent 就会带着这些历史去做事。

### 9.1 三种可见范围（权限规则）

新建或编辑记忆时，「可见性」有三个选项，规则由服务器强制执行：

| 选项 | 代码值 | 谁能看到 |
|---|---|---|
| 团队可见 | `team` | **全员**都能看到、能搜到（任务完成后自动沉淀的记忆，默认就是这一档） |
| 仅自己 | `private` | **只有作者本人**。注意：管理员在界面里**也搜不到、看不到**别人的私有记忆 |
| 指定成员 | `restricted` | 只有**作者 + 你勾选的那几位成员**能看到；创建时**至少勾 1 位**，否则服务器会报错 |

补充说明：

- 编辑和删除的权限是「**作者本人或管理员**」。别人的记忆，你看到的提示是「仅作者/管理员可改」；
- 检索和展示**都**按上面的规则过滤，所以「搜不到」通常等于「你没权限」，不是系统坏了。

### 9.2 怎么搜记忆

记忆 Tab 顶部一行是检索区：

1. 「搜索记忆」输入框：输入关键词，按 **Enter** 或点「搜索」；
2. 「全部类型」下拉：可筛选 **决策 / 偏好 / 事实 / 结论** 四种类型；
3. 「全部可见性」下拉：可按 仅自己 / 团队可见 / 指定成员 筛选；
4. 结果按时间倒序，一次最多 100 条。

关于关键词的两个实用提示：

- 中文 **3 个字及以上**的词走索引检索，命中更准；
- **1 到 2 个字的短词**走的是包含匹配兜底，所以「数值」这种两字词也能搜到（界面提示「≥2 字中文可命中」）；
- 搜不到时：换更长、更具体的词，或者换一种说法试试。

### 9.3 新建、编辑、删除记忆

- 点右上角的「新建记忆」按钮，右侧会滑出表单（按钮文字以实际界面为准）：
  - **类型**（决策 / 偏好 / 事实 / 结论）；
  - **标题**（必填，最长 200 字）；
  - **内容**；
  - **标签**：逗号分隔，例如 `报价,口径`；
  - **可见性**：见 9.1；选「指定成员」时必须勾选成员；
- 卡片上的「编辑 / 删除」只对作者本人或管理员显示；删除有二次确认，**不可撤销**；
- 每条记忆卡片上都会显示类型徽标、可见性徽标（仅自己 / 团队可见 / 指定成员）、作者和时间；
  「指定成员」的卡片还会列出可见成员名单。

### 9.4 记忆是从哪来的（三个来源）

1. **任务完成时自动沉淀**（最主要）：任务「已完成」（含审批通过）后，系统会自动写一条**结论**类记忆，
   标题是「任务结论：<你的任务标题>」，内容包括任务摘要、执行 Agent、结论、产物目录路径，
   如果有审批修正意见也会写进去。同一条任务只沉淀一次，不会重复；**失败的任务不沉淀**。
2. **你手动新建**：记忆 Tab 里的「新建记忆」。
3. **系统其他环节**：@Agent 咨询有明确结论时、每天生成的画像，也可能作为记忆入库。

> 闭环长这样：**做任务 → 出产物 → 自动沉淀记忆 → 下次发任务时 @ 引用这条记忆 → Agent 带着历史去做**。
> 想验证效果，可以在第二次任务的描述里引用第一次任务的结论记忆，它一般会在回答里体现「基于上次的结论」。

## 十、常见问题（自助排查）

### Q1：@ 了 Agent 或给它发消息，它一直不回 / 一直显示「正在唤醒」

按顺序做这几步：

1. **先等**：休眠中的 Agent 需要唤醒，上限 60 秒，加上生成时间，慢的时候一两分钟很正常，
   页面上会显示「正在唤醒 xxx…」；
2. **看有没有红色报错**：如果出现「Agent 启动失败，请管理员检查」，说明是服务器侧的问题，
   把这句话截图发给管理员，自己解决不了；
3. **确认它没被停用**：去「设置 → Agent 工坊」，看这个 Agent 有没有「已停用」红色标签，
   或者卡片状态是不是灰点、显示「休眠中」。已停用的 Agent 不能被 @ 起来；
4. **换一个 Agent 试试**：如果别的 Agent 能回，说明是这一个的问题，报给管理员；
5. **刷新页面重试一次**：排除偶发的网络抖动。

### Q2：上传文件失败

1. **先看大小**：单个文件上限 **10MB**。超过 10MB 一定会被拒绝，请改用「添加链接」
   把网盘链接贴进来（这是 SPEC D14 的规定，不是 bug）；
2. **看提示文字**：页面顶部会给出具体原因（「文件超过 10MB 上限…」等），照着提示改；
3. **换个名字**：文件名里带 `/ : * ? " < > |` 这类符号的，服务器会把它们替换掉，
   极少数情况下会造成困扰，改成普通名字即可；
4. **确认自己还在登录状态**：登录态失效（超过 7 天）时上传会失败，重新登录再来；
5. **附件不要发在 Agent 直聊里**：直聊模式不支持附件，请到会话里发。

### Q3：通知不弹出来

1. **先确认开关**：「设置 → 通知」看是「已开启」还是「已关闭」，点一下切换成已开启；
2. **检查浏览器权限**：点「申请 / 检查权限」，权限要显示 `granted`；
   如果显示 `denied`（曾经点过「拒绝」），需要到浏览器地址栏左侧的站点设置里手动改回「允许」；
3. **点「发送测试通知」**：能弹出来说明链路通了，弹不出来就是权限或系统级通知被屏蔽了
   （检查操作系统是否开启了「专注 / 勿扰模式」）；
4. **用当前路径时这是已知限制**：现在用的是 IP + 自签名证书，浏览器不认它是安全环境，
   **桌面通知和「添加到主屏幕」可能整个用不了**，这是 SPEC D13 里「域名 + 正式证书解锁 PWA 通知」
   要解决的问题。此时只能看顶栏 🔔 的站内提醒；
5. **iPhone / iPad**：必须先在 Safari 里「添加到主屏幕」，再从主屏图标打开，通知权限才可用。

### Q4：新同事注册了，但是登录不了，一直说「账号待管理员批准」

- 这是设计如此（SPEC D7：第一个注册的人是管理员，之后注册的人需要被批准）；
- **当前版本的界面上还没有「批准成员」的按钮**，所以需要**口头联系管理员**处理；
- 判断依据：注册时如果页面提示「注册成功，待管理员批准后可登录」，就是卡在这一步了。

### Q5：任务一直「排队中」，或者一直「执行中」

1. **排队中**：说明这个 Agent 前面还有任务。打开任务详情看「前面还有 N 人」——
   N 包含正在跑的那个。同一个 Agent 同时只跑一个任务，这是设计；急的话换一个 Agent 重新提交；
2. **执行中很久**：办公任务要调工具、写文件，几分钟很正常。默认 10 分钟没返回会判超时失败；
3. **状态从「执行中」变回「排队中」**：说明服务器重启过，系统自动把中断的任务重排了，
   这是自愈行为，不用管，等着就行；
4. **想放弃**：点「取消任务」（仅创建者/管理员，且只在排队中/执行中/待审批可取消）。

### Q6：搜不到某条记忆

1. **先换关键词**：用更长更具体的词，或者换成同义说法；两三个字的词反而更容易命中；
2. **清掉筛选条件**：把「全部类型」「全部可见性」都恢复成「全部」，可能之前选窄了；
3. **确认权限**：「仅自己」的记忆别人（包括管理员）看不到，「指定成员」的记忆只有名单里的人能看到，
   搜不到是权限正确生效的表现；
4. **确认它没被删**：作者或管理员删除后，记忆就真的没了，删不可撤销。

## 十一、行为边界：有些指令会自动转人工审批

### 11.1 这不是故障，是设计

你在任务描述（或引用的资料名、引用的记忆标题）里写了某些内容时，任务**执行完不会直接完成**，
而是停在「**待审批**」，必须由人点一下才算交付。这是 SPEC v3.2 的 **D36「不确定性升级规则」**，
目的是让「需要有人负责的决定」永远有人负责。

会被自动拦截的三类内容（关键词命中即触发，大小写不敏感）：

| 类别 | 会触发的典型词 |
|---|---|
| **金额 / 预算** | 金额、预算、报价、费用、成本、定价、价格、付款、支付、发票、万元、合同额 |
| **对外承诺** | 对外、承诺、合同、签约、客户、甲方、乙方、发布、公告、公开、上线通知 |
| **删除数据** | 删除、清除、销毁、清空、卸载、覆盖、drop、delete、truncate |

小提示：系统做了词例外处理，比如「客户端」不会因为含「客户」两个字而被误判成对外承诺。
但你如果确实要谈预算、谈对外发布、谈删文件，就应该走审批，这是好事。

除 D36 之外，**D17 审批节点**同样要求人工确认：**设计定稿 / 预算 / 对外承诺**。

另外还有两种「自动转人工」的情况：

- Agent 自己声明「**低置信**」（没把握）时，会先请值班 Agent 复核；复核不可用时，保守升级为待审批；
- 你在发起任务时手动勾了「需要人工审批」。

### 11.2 四个预设 Agent 各自的边界（来自它们的 SOUL.md）

每个 Agent 的 SOUL.md 里都写了固定的【行为边界】四段：**可自主 / 需升级人审 / 禁止 / 失败兜底**。
摘要如下（完整内容以服务器上的 SOUL.md 为准）：

| Agent | 可自主（举例） | 必须升级人审（举例） | 明令禁止 |
|---|---|---|---|
| 策划 Agent `cehua` | 写非定稿的设定草案、剧情大纲；数值试算并标注「试算稿」；出 2 个备选方案对比 | 世界观/主线/角色的**定稿**；任何涉金额成本的内容；对合作方/玩家的承诺表述；删除或覆盖已有设定数值 | 未经负责人确认擅自宣布任何产出为「定稿」 |
| 程序 Agent `chengxu` | 写、调、重构非关键路径代码；技术选型调研；读代码跑只读命令；写技术文档 | 架构/数据模型/接口契约的**定稿**；涉金额与云成本；对外技术承诺与交付时间承诺；删文件、清库、`rm -rf` 类操作；破坏性变更（改接口签名、改 schema、改部署方式、升主版本） | 未获批准时执行破坏性变更 |
| 评审 Agent `pingshen` | 读任何文件代码产物做审查；跑只读命令；输出问题清单（严重度+位置+建议） | 给「定稿通过」结论前；审查涉金额内容；审查将要对外发布的材料；认为该删东西时（**只提建议**） | 修改/删除/重命名任何被审查对象；**直接动手修**（哪怕只有一行）；没读充分就给「通过」 |
| 值班 Agent `zhiban` | 读看板/文件/通知，生成晨报、周复盘、画像；写报告文件；发例行通知邮件；复核别人的「低置信」产出 | 复核涉及定稿内容；报告涉及金额成本；对外发送的催办内容涉及承诺；清理过期通知或产物时（**只提建议**） | 编造或美化进度、风险、完成度等任何汇报数据 |

其中值班 Agent `zhiban` 还承担两个兜底职责：**复核其他 Agent 标记为低置信的产出**，
以及在系统层面作为「复核不可用时的保守升级」的执行方。

### 11.3 遇到「待审批」时该怎么做

把它理解成「Agent 提醒你：这件事需要有人拍板」。正确处理姿势：

1. 打开这条任务，先看「执行结果」摘要和产物，判断它做得对不对；
2. 在「审批意见」里写清你的判断（必填）；
3. 选一个按钮：
   - 觉得没问题 → **通过**，任务完成并把结论沉淀成记忆；
   - 方向对但细节不行 → **修改**，写上「哪里不行、应该怎样」，任务会带着你的意见重新执行，
     而且这条意见会被这个 Agent 记 30 天，下次同类任务它会先看到（D35）；
   - 完全不能用 → **打回**，任务失败；
4. 如果你不是这个任务的创建者、也不是管理员，你看不到审批按钮——请找创建者或管理员处理。

## 十二、协作三种方式与 Agent 使用（S4.1 实测补充）

### 12.1 三种协作方式（成员之间怎么聊都不花钱）

| 方式 | 怎么用 | 谁看得见 | 备注 |
|---|---|---|---|
| **私聊** | 新建会话 → 选 **1** 位成员 | 只有你们两人 | 私聊就是 **2 个人**；同一对人再建一次会回到同一个会话（不会重复） |
| **群聊** | 新建会话 → 选 **≥2** 位成员 | 群内全部成员 | 可以给群起名字 |
| **任务指派** | 任务 Tab → 发起任务 → 选 Agent | 按任务可见性（团队/私有/受限） | 走任务中心，Agent 在后台干活并产出文件 |

**成员之间聊天（私聊 / 群聊，不 @Agent）不调用大模型、不产生任何花费。** 实测口径：连发 4 条消息前后，计费表（`usage_log`）新增 **0** 条记录。
花费只在两种时刻产生：① 你在聊天 Tab 直接跟 Agent 对话；② 你在群里 `@Agent`。

### 12.2 群聊里 @Agent 的规矩
- 写 `@值班Agent` 或 `@zhiban` 都能点名（Agent 的 id 与显示名都认）；
- 被点名的 Agent **答一次就离开**，不会赖在群里持续收听；
- 它看到的是**最近 20 条 / 24 小时内**的会话片段 + 一句「你被 @ 拉入做一次临时咨询」，**不是**完整历史。想让它看完整上下文，请在提问里复述关键结论；
- 一次 @ = 一次计费调用（实测约 1.8 万输入 tokens ≈ ¥0.019）。

### 12.3 谁能用哪个 Agent（现状，如实告知）
- **任何已登录成员都能唤起任意一个「已启用」的 Agent**（直聊或 @ 皆可）。当前系统**没有**「A 成员只能使用 Agent X」的细粒度授权。
- 管理员可「停用」某 Agent：停用后**全员**都用不了它（`POST /api/chat` 返回 403）。
- 若要「按成员授权 Agent」，属待决策项：方案对比见《Session4.1-降耗与能力报告》C5 节（**本次未实现**，避免超范围改动）。

### 12.4 新建/删除 Agent（管理员，实测创建 2.9 秒）
1. 设置 → Agent 管理 → 新建；
2. 填 **id**（小写拼音/字母数字，2–32 位，如 `yunying`）、**显示名**、**描述**、**SOUL.md 人格与边界**（建议保留 `【行为边界】` 段落，系统会校验）；
3. 提交后系统自动完成：从 `cehua` 克隆配置 → 分配端口（8650–8999）→ 写 `.env`（600 权限）→ 安装 systemd 单元（**不立即启动**）→ 写入注册表；
4. **懒启动**：刚建好处于「未运行」，第一次有人跟它说话才唤醒（实测首次对话 15.8 秒含唤醒，之后很快）；无人使用时自动休眠，不占内存；
5. **删除**：Agent 管理 → 删除。预设 4 个（策划/程序/评审/值班）**不可删**，只能停用。实测删除会一并回收端口、清理 profile 目录、systemd 单元与 drop-in 目录（实测残留 0）。

### 12.5 「想看就点一下，不点不花钱」——按需作业与花费入口

| 想看什么 | 命令（管理员在服务器执行） | 花费 |
|---|---|---|
| 今日数据快照（看板/未读/新增/余额） | `python3 /opt/team-console/ops/digest.py` | **0** |
| 本周花费估算与 Top5 | `python3 /opt/team-console/ops/digest.py --cost-only` | **0** |
| 周报（AI 判断与建议） | `bash /opt/team-console/ops/run-job.sh weekly` | ≈¥0.069/次 |
| 团队画像刷新 | `bash /opt/team-console/ops/run-job.sh profile` | ≈¥0.09/次 |

- **定时作业只剩两条**：每日 06:00 数据快照（0 token）与每周一 09:00 周报（AI 版）。其余一律「想看再点」（原 15 次 LLM 作业/周 → 1 次/周）。
- 成员不需要自己跑命令：周报、快照、画像都会自动落到「通知」与「画像」Tab 里。
