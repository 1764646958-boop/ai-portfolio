## 二、为什么这样分工具（网络现实）

- **Claude Code 在境内服务器上跑不通**（Anthropic API 境内直连不可用，服务器上装代理得不偿失）
  → 推荐：**在你本地电脑跑 Claude Code**（已有 Clash 代理），让它通过 `ssh root@<服务器IP>` 操作服务器。S0 的命令都是干净的远程配置操作，适合这种模式。
- **Kimi Code 在境内网络友好** → 推荐：**直接 SSH 登录服务器，在 `/opt/team-console` 里跑** `kimi`，省去本地↔服务器来回。

## 三、Kimi Code 运行方式（S1-S4 通用）

```bash
# SSH 登录服务器
ssh root@<服务器IP>
cd /opt/team-console

# 方式 A（推荐）：交互式 + 免批准，然后粘贴执行稿全文
kimi --yolo -m kimi-code/k3-256k

# 方式 B：非交互一次性执行（把执行稿存成文件后用 -p 喂入）
kimi -m kimi-code/k3-256k -p "$(cat /opt/team-console/prompts/工具版/Session1-KimiCode执行稿.md)"

# ⚠️ 必须带 -m kimi-code/k3-256k（K3 的 256K 版本，本套餐可用）：
#    不要用无后缀的 k3（1M 版，需更高档位会报 401）——用 -m 显式指定即可防复发。
```

> **服务器首次准备（一次性）**：① 安装：`npm install -g @moonshot-ai/kimi-code`（2026-09-13 已装好）；② 登录：`kimi` 内输入 `/login` → 选「Kimi Code (OAuth)」验证码流程（任意设备打开链接、登录并输入验证码）。
> 执行稿已于 2026-09-13 上传到服务器 `/opt/team-console/prompts/工具版/`（全部 7 份）；如需重新上传：`scp -r "D:\learn\saishi\chcz\CloudLoom\Session提示词\工具版" root@<服务器IP>:/opt/team-console/prompts/`

- `--yolo` 只跳过普通工具审批，**请确保你信任该目录**（服务器 /opt/team-console）。
- ⚠️ **必须在 root 用户下运行**（Kimi 安装在 root、登录也在 root）：若你登录的是 ubuntu，先执行 `sudo -i` 切到 root 再跑；直接以 ubuntu 运行会因系统 Node 版本过低报 `createZstdDecompress` 错误（2026-09-13 实际踩坑记录）。
- 上下文很长时用 `/compact`；中途断了用 `kimi -C` 继续。
- 建议先 `/init` 生成 `AGENTS.md`（让 Kimi 记住项目结构），质量会更好。

## 四、Claude Code 运行方式（S0）

```powershell
# 本地（Windows，已有代理）安装一次
npm install -g @anthropic-ai/claude-code
claude          # 在任意目录启动
# 把 Session0-ClaudeCode执行稿.md 全文粘贴，然后按提示批准命令
```

- 本稿里的命令默认「在服务器上执行」；Claude Code 在本地运行时，它会自行用 `ssh root@<服务器IP> '<命令>'` 的方式执行（稿子里已写明这个约定）。
- 关键操作（写 /etc/hermes.env、systemd 单元、.env）会让 Claude 请求批准——**逐条看，别开全自动**。

> 🔁 **S1-S4 同样可用本模式**（2026-09-13 起）：Kimi 触发 5 小时限额等情况时，直接用本机 Claude Code 执行 S1-S4——完整步骤与**粘贴用提示词**见同目录 `00B-ClaudeCode执行说明.md`。

## 五、批次交接约定（工具版新增）

每批结束**必须**把产出报告写到服务器：`/opt/team-console/reports/SessionN-*.md`。
下一批的执行稿会**先读上一批报告**再开工（这就是"一次性执行"能成立的原因：不依赖聊天记录，只依赖服务器上的文件）。

## 六、铁律（所有批次通用）

1. 开工先读 `/opt/team-console/SPEC.md`；决策清单（第四节）不得偏离
2. 严禁跨批改动：只在前批已验收代码上新增，不重写
3. 每步验证失败 → 先诊断再继续，**禁止静默跳过**
4. 所有密钥只进 `.env`；报告中脱敏
5. 不确定参数以 `hermes --help` / 实际输出为准
6. 域名/备案未就绪时走降级路径（对外 HTTPS 延期 → Session 4 收口）；**不得以 IP 直连对外**（SPEC 约束 B2）；延期项必须显式标注
