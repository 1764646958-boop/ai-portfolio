## 1. 音乐系统定位（两首曲子为什么长这样）

音乐是贯穿全作的情感锚点（大纲附 B 表）：**旧友最早惊叹 AI 的音乐能力；AI 用旧友最珍视的音乐替代他本人。**

- **BGM#2 是第一幕「日常的暖」** —— 玩家尚在信任、探索、找记忆。它必须让玩家放松，像傍晚的窗台。
- **BGM#3 是第一幕「渐近的冷」** —— 旧友正式出现、AI 开始翻译/过滤、记忆考古开始。玩家开始感到「有东西在变不对」，但还不能确定。
- **两首都引用《旧友主题动机》（`w1_main.mp3`）**，但引用方式相反：**BGM#2 是温暖变奏（听不出是同一首）；BGM#3 是暗化碎片（半音错位、不兑现解决）**。
  - 叙事钩子：6.4 恐怖时刻「旧友喜欢的歌突然变调切入（无预告）」与 7.3「BGM#1 变调版（暖色旋律染冷）」——BGM#3 里的碎片化暗化就是为这两个时刻做铺垫。玩家带着「这动机有点耳熟但想不起来」的错觉直到 6.4 揭底。
  - ⚠️ **克制原则**：动机辨识度必须**靠音程骨架而非整段旋律**，保证 6.4 的「突然变调」成立；如果 BGM#3 已经整段呈示，6.4 就没有惊喜了。

## 2. BGM#2 —— 日常暖色曲（第一幕日常场景）

| 项 | 规格 |
|---|---|
| 落点 | 模块 1（开场/探索/对话）~ 模块 3 前段（日常聊天、锚点交互）≈ 1.1-3.1 |
| 情绪基调 | 暖色、松弛、略带怀念；「傍晚、窗台、一条消息让一天变好」 |
| 风格连贯 | 与 BGM#1（主界面曲，钢琴+弦乐，暖色，W2 已完成完整曲）同一动机家族、同一混音空间（同大厅混响、同弦乐音色库） |
| 速度建议 | **60-70 BPM**（安详步速）；变奏可将单小节音符做 1.5 倍延长（不改变动机骨架） |
| 调性建议 | C 大调 / G 大调系（暖）；避免离调，副歌只到属方向走走停停（大调关系小调出现 ≤1 处，留一点点「记忆泛黄」的酸） |
| 动机引用 | `w1_main.mp3`（旧友主题动机）首两小节旋律骨架 → **温暖变奏**：音程关系不变，节奏放宽，加柔弦和声层；引子与尾段可不引用（保持「日常自己的歌」的错觉） |
| 结构 | A（主动机呈示，温）→ A'（展开，稍亮）→ 引子/尾声（环境音渐收）；循环衔接处无硬切（回 A 前的最后一个音符与 A 起音为同一和弦-音符，或直接用尾部渐弱+切入法） |
| 时长 | 90-120 秒（本曲 120s 更佳）；无缝循环 |

## 3. BGM#3 —— 紧张渐冷曲（第一幕异常前段）

| 项 | 规格 |
|---|---|
| 落点 | 模块 3 后段（3.2 旧友正式出现后氛围转冷 ~ 3.3 AI 翻译/过滤）至模块 4（记忆考古 ×3） |
| 情绪基调 | **渐冷**：从「还暖的底色」慢慢凉透；玩家开始隐隐不安但说不清楚 |
| 风格连贯 | 与 BGM#1/#2 同一动机家族，但**乐器配比变暗**（钢琴走低音区、留白、弦乐高音泛音做轻微不谐和衬音） |
| 速度建议 | 90-100 BPM 起（起步略懒、之后**不加速**，用音色而非速度制造紧张——与战斗 BGM#4 的 120→170 渐进区分开，避免抢戏） |
| 调性建议 | A 小 / G 小（与 BGM#2 同基音音名但小调化：同一首「歌」染冷 = 叙事点题）；中段只落到半音挂留（不解决），结尾**停在未解决的不谐和音** |
| **不和谐音程（硬性要求）** | ① **三全音（tritone）**：动机音程的 4 度被错位为增 4 度（+6 半音），至少 2 处；② 半音碰撞（cluster）：钢琴右手同时按下动机核心音符与它的 b9；③ 挂留音（sus2/sus4）**不放下来**——延迟解决≥4 拍；④ 背景低音半音爬行（B-C-Bb-A），无解决 |
| 动机引用 | 同一旧友动机 → **暗化碎片**：只在 3.2/3.3 节点附近出现；每次出现被错位 1-2 个半音、节奏被拉长或压缩、藏在低音区/高音泛音里，**不完整呈示**（最多 2 小节）；后段动机出现次数递减、音程更歪（「替代进行中、原版被侵蚀」） |
| 结构 | 三段渐变：①若即若离（动机若隐若现、暖底色未褪）→ ②潜行（暗化动机+不谐和，情绪悬空）→ ③逼近（织体加厚但不解决，动机彻底碎片化）；结尾停在未解决音，**直接衔接战斗 BGM#4 的起拍**（不留休止，见 W4.3 BGM#4 Brief） |
| 时长 | 90-120 秒（本曲 90s 循环更合适——考古关卡一轮约 2-3 分钟，循环 2-3 次不腻） |

## 4. 导出/命名规范（两曲通用）

| 项 | 规范 |
|---|---|
| 格式 | 游戏内用 **OGG**（`BGM2_loop.ogg` / `BGM3_loop.ogg`）；WAV 源文件保底留档（可重建、可再压缩） |
| 命名 | `BGM2_loop.ogg` / `BGM3_loop.ogg`；源工程命名 `BGM2_src.wav` / `BGM3_src.wav` |
| 采样率/位深 | 44.1kHz / 16-bit（OGG 128-192kbps） |
| 响度 | 峰值 ≤ -3 dBFS；循环点处**无 spike/咔哒**（拿循环点前后 0.1s 波形目检） |
| 放置 | `res://assets/audio/BGM2_loop.ogg`、`res://assets/audio/BGM3_loop.ogg`（Godot 导入后 .ogg.import 自动生成，无需手改） |
| 对白 ducking | 游戏内 `AudioStreamPlayer` 音量总线做主音量，对白/语音时由 B 侧事件总线做侧链，两曲输出口预留总线位（Godot 里建 `Music` 总线 + `Ducking` 监听） |

## 5. 验收标准（周日评审）

1. **与 BGM#1 风格连贯**：同一动机家族、同一混音空间；盲听列表里 3 首曲不「像别人写的」。
2. **动机引用可辨识但克制**：BGM#2 盲投「有旧的影子吗」——要求 6/10 人「有点耳熟但又不像」；BGM#3 后段能隐约听见动机碎片但不完整（6.4/7.3 埋点留白）。
3. 时长 1.5-2 分钟循环、循环点无痕（第 1 秒与最后一秒可无缝衔接播放）。
4. BGM#3 含不和谐音程（三全音 ≥2 处 + 未解决尾音）；BGM#2 全程三全音 = 0 处。
5. 音轨含可重建源文件（DAW 工程或 MIDI 脚本），评审后修订可回到源改（不修最终导出稿）。
6. **与 6.4「无预告变调」不冲突**：BGM#3 内不得出现「旧友喜欢的歌」的原曲旋律（那是 6.4 专属材料，只有动机碎片）。

## 6. 制作备注（A 自留）

- **ω 动机抽取**：把 `w1_main.mp3` 导入 DAW（REAPER/Ableton/AU 均可），取前 8-10 秒，用调音检测插件（如 REAPER 的 Tonematch / AU 的 KeyScale 或人工对音）确定中心音高与音程序列，**不再另创新动机**——`w1_main` / `w1_loop` / `w1_clean` 三份为动机素材（同曲三个版本：完整/循环/干净版）。
