# BGM#4 作曲 Brief（W3.5 同族 · W4.3 战斗曲）

> 交付物 W4.3 · 成员 A · 2026-08-31（作曲 Brief；成曲由 A/作曲 值守产出）
> 用途：5.1 战斗触发 → 5.4 最终抉择（90s）/ 后摇（30s）/ 音乐线索埋点 6.4 / 7.3
> 前置：BGM#1 主界面曲已入库（assets/audio/w1_loop.mp3）；BGM#2/#3 Brief 为 W3.5（same 家族）

---

## 1. 定位一句话

**冷色弦乐+电子颗粒的战斗体**：借 BGM#1 的「钢琴+弦乐暖色」家族血缘（听众听见「同一部作品里的另一个房间」），把动机剥去温度、碾碎、重新排列——不铺鼓，节奏交给引擎的心跳层（`battle_audio.gd` 程序合成）。

## 2. 规格

| 项 | 规格 |
|---|---|
| BPM | 120 起，每 15s +10 → **纯音乐不加速、鼓不写**；与压力表 heartbeat 表一致（t=65 行 170，**B4 冲突见 §8**） |
| 调性 | A 小调 / G 小调（冷）；与 BGM#1 的 C/G 大调形成「同族异色」 |
| 时长 | 1.5-2min 无缝循环（战斗 90s + 后摇需可循环接入） |
| 和声 | 三全音 ≥2 处（减五/增四）；半音碰撞（相邻半音对）≥1 处；挂留音**不解决**；低音半音爬行（静态悬置式驱动） |
| 织体 | 弦乐长音/scratch 音（同 BGM#1 弦乐音色库，滤波变冷）+ 合成器颗粒（noise texture、BPM 同步子音）+ 极低音量副旋律线 |
| 动机 | **旧友主题动机碎片化**：0-30s 不可辨认的碎片（单音符点刻，如 12 音细分的一个颗粒）→ 30-60s 半句出现、时长含混 → 60-90s 近完整但变调/微扭曲（六度闪变） |
| 乐器 | 能复用 BGM#1 弦乐音色包（同族）；不加钢琴（钢琴=温馨面，战斗让开） |

## 3. 分层（供 battle_audio strings 层复用）

作曲工程内做 **stem 分组导出**，battle sync 用元素层：

| stem | 内容 | 用途 |
|---|---|---|
| `battle_strings.ogg` | 弦乐/scratch 层（BGM#4 去颗粒去掉的合奏部分） | → `res://assets/audio/battle_strings.ogg`（w4.3 battle_audio strings 层） |
| `BGM4_loop.ogg` | 完整混音（弦乐+颗粒，无鼓） | → `res://assets/audio/BGM4_loop.ogg`（整曲，B 的 BGM 系统/特殊场合） |
| （可选）`friend_motif.ogg` | 旧友动机 solo（有 warmth 的弦乐/琴音片段，极短 8-12s loop） | → `res://assets/audio/friend_motif.ogg`（battle_audio friend 层；断续/持续由引擎控制） |

> **互斥注解**：`BGM4_loop.ogg` 与 `battle_strings.ogg` 不混放（同素材不同混音）；正式战斗链路=heartbeat(合成)+battle_strings+friend_motif+noise(合成)，BGM4_loop 供非战斗播放/预览用途。

## 4. 与 BGM#1-#3 的动机网

| 曲 | 关系 |
|---|---|
| BGM#1 | 主界面暖色（钢琴+弦乐）；本曲=同弦乐音色家族，变冷 |
| BGM#2 | 日常暖色（60-70bpm）；本曲的「前奏」——战斗前 BGM 由 #2 静默抽走 |
| BGM#3 | 紧张渐冷（90-100bpm）；本曲为强度二段跳，动机暗化承接 #3 |
| **本曲 #4** | 战斗层；旧友动机碎片化+变调（第 3 次出现的旧友主题，与 6.4 的「旧友喜欢的歌」呼应） |
| 6.4 | **旧友喜欢的歌突然变调**（音乐线索第一次显性化）：取旧友主题动机的变调版本（本曲已埋），1-2 帧嵌入 |
| 7.3 | BGM#1 变调版（暖色染冷）——与 6.4 的变调一致，首尾呼应 |

## 5. 导出规范


命名沿用 w1_loop.wav → ogg 惯例（**W3.5 已改用 .ogg**；若有 composer DAW 会导出 wav，请转 ogg 并按上述入径）。

## 6. 验收标准

1. 单独播放 15s：能听出与 BGM#1 同族（弦乐音色、对位气质）但明显冷色——**不像是同一首曲子**。
2. 与 bpm 曲线核对：作曲工程里听感 t=0/15/30/45/60 处转折不突兀（心跳层节奏由引擎提供，本曲鼓点缺席正常）。
3. 三全音/半音/挂留检查表：处数达标（≥2 / ≥1 / ≥1）。
4. 旧友动机碎片 0-30s 存在但「似有若无」；30-60s 半句可辨认——对照 W3.2 考古 reveal 的旧友语境。
5. *B4 定稿为 160 上限*：按 120-160 区间重排（t=60-90 为 160 锚定）。**备注**：battle_audio.gd 的 BPM_TABLE 同步改一处即好。

## 7. 时间轴参考（音画对齐，可给 composer 打点用）

| 时间 | 画面/玩法 | 音乐意图 |
|---|---|---|
| 0-30s | 认知入侵（侵蚀 0→0.4） | 单薄定奏；动机碎片开始落点；每 8-10s 白噪爆发（引擎） |
| 30s | 记忆崩塌开始 | 织体加厚一层；旧友动机半句出现（30-60s） |
| 45s | 绿通道滤除、posterize 加重 | 高音尖刺半音 +1 |
| 60s | 最终抉择 | 张力峰（不解决 4→5 拉满）；动机近完整但变调 |
| 90-120s | 后摇退散 | 尾音停留（长音衰减）→ 衔接 7.3 BGM#1 变调版（暖色染冷）；无预告留白 |
