# 战斗音频实现说明（W4.3）

> 交付物 W4.3 · 成员 A · 2026-08-31

> 数据源：W3.3 `pressure_params.json`（curves / heartbeat_bpm / phase1-3.audio / aftermath / battle_audio_layers）
> 补交：`defense-line-dev\assets\audio\sfx_glitch.wav`（**W3 待人工 #2 闭环**：0.5s 白噪/电流音，已生成入库）

## 1. 四层音轨

| 层 | 资源 | 依赖 | 音量/节奏（pressure_params 依据） |
|---|---|---|---|
| heartbeat 心跳 | **程序合成**（AudioStreamGenerator 正弦 thump，无需资源） | 无 | bpm 阶梯：`min(170, 120+floor(t/15)*10)` 按表编码；thump 85Hz 主叩+220Hz 次叩、0.30s 包络；压力越高振幅 +6% |
| strings 弦乐 | `battle_strings.ogg`（BGM#4 元素层） | 缺失→层禁用 | phase1 0.8 → phase2 30-60s 线性 0.8→0.5 → phase3 0.4 → aftermath 淡至 -30dB |
| noise 白噪 | **程序合成**（白噪短爆） | 无 | 0.5s/次、指数包络 τ=6；间隔 phase1 [8,10]s / phase2 [7,9]s / phase3 [6,8]s；压力 0→1 使间隔 ×1.15→×0.8 |
| friend 旧友动机 | `friend_motif.ogg` | 缺失→层禁用 | phase1 关；phase2 0.5 断续（方波 1.4s：0.75 开 / 0.65 沉）；phase3 0.6 持续清晰；aftermath → 0 |

> 分工注解：BGM#4 作曲 Brief 中的「完整战斗 BGM」= strands 层素材的来源；**引擎节奏（心跳）一律程序化**，作曲不写鼓——避免与心跳层打架（音画设计 §5.1-5.4）。

## 2. 时间轴对照（0-90s + 后摇）

| 段 | 时间 | bpm（阶梯表） | strings | noise 间隔 | friend |
|---|---|---|---|---|---|
| phase1 | 0-30 | 120→130 | 0.8 | 8-10s | 关 |
| phase2 | 30-60 | 140→150 | 0.8→0.5 线性 | 7-9s | 0.5 断续（t≈55s 起段落清晰化——md 表注「♪清晰」） |
| phase3 | 60-90 | 160→170（表 t≥65 写 170） | 0.4 | 6-8s | 0.6 持续 |
| aftermath | 90-120 | 110 定值 | -30dB 淡出 | 停 | →0 |
| 结束 | 120+ | stop_battle(2.0s) 全层淡出 | | | |

> ⚠️ **B4 冲突点**（W3.3 待确认）：`heartbeat_bpm` 公式 t=60-74 应为 160，但逐 5 秒表在 t=65 写 170（表优先已编码）。B 定稿后：改 `battle_audio.gd` 的 `BPM_TABLE` 一处即可（`class_name BattleAudio` 常量）。

## 3. 公共 API（B/C 侧调用）

```gdscript
BattleAudio.start_battle()                       # 5.1 战斗触发时（心率 120 起）
BattleAudio.set_phase("phase2")                  # 0/30/60s 交界（battle_post_controller 已含时点）
BattleAudio.set_pressure(0.85)                   # W4.1 契约 pressure_level（0.75 - drift*0.03 钳位）注入
BattleAudio.trigger_glitch(true)                 # 考古 4.x.5 记忆闪烁（仅音效）
BattleAudio.trigger_glitch(false)                # 战斗 QTE 选错（音效 + battle_audio_glitch 信号→视觉裂纹）
BattleAudio.stop_battle(2.0)                     # 后摇结束
```

**信号**（battle_audio.gd 自声明，A 与 EventBus.gd 零耦合，B/C 直接 connect）：

```gdscript
signal battle_audio_phase_changed(new_phase: String)   # phase1/2/3/aftermath
signal battle_audio_glitch(burst_only: bool)           # 音效 + 可挂视觉（W4.4 crack/flash）
```

**查询**：`BattleAudio.get_bpm()`（HUD 可显示心跳速率）、`BattleAudio.is_running()`。

## 4. 降级语义（任务要点：资源缺失静默降级）

| 情况 | 行为 |
|---|---|
| strings/friend 资源不存在 | 该层 `_try_load_player` 返回 null → **层禁用**（推 warning 一次，不崩溃，不弹窗） |
| glitch wav 不存在（应先补交已办） | `trigger_glitch` 变纯信号广播 |
| `start_battle` 时未注册 autoload | 调用方 get_node("/root/battle_audio") 前判非空；直接可用 `class_name BattleAudio` 实例化任意场景（非 autoload 也能用） |
| 无心跳（合成器失败） | can_push_buffer 全防御，跳过一拍 |

## 5. 集成（给 B 的 3 行）

```gdscript
# project.godot → [autoload]
battle_audio="*res://scripts/battle_audio.gd"      # 与 ambient_director 同区
```

1. 战斗场景入口（battle_post_controller 或 battle_test.gd）调 `BattleAudio.start_battle()`。
2. 三个时点（0/30/60s）调 `set_phase`；W4.4 controller 会统一驱动（**W4.4 完成后 controller 接管时点，battle_audio 只接 API**）。
3. 若想给战斗单挂 SIDE-CHAIN（心跳压低 old BGM）：新建 Audio Bus「Battle」，把四层 `.bus` 指向它——代码已留 `_try_load_player(path, bus)` 参数位（默认 Master）。
