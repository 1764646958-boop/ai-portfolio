# UI 详细设计标注 · 四套对话界面

- **成员**：C
- **用途**：`dialogue_ui_wireframes.md` 的**精确标注版**（尺寸 / 间距 / 颜色 / 四状态），供 D 出图 + 自己 W2 实现
- **基准分辨率**：**1920×1080**（16:9），所有单位 px，按百分比/锚点布局避免拉伸
- **颜色均为参考值**，最终以 D 视觉定稿为准；但**冷暖二元对立**必须保留（见下）

### 四状态通用规则（每套 UI 的交互元素都要覆盖）

| 状态 | 规则 |
|---|---|
| 正常 Normal | 基础色，opacity 100% |
| 悬停 Hover | scale **1.05**，或底色加深一档 |
| 点击 Pressed | scale **0.98**，底色再深一档 |
| 禁用 Disabled | opacity **40%** + 去饱和置灰 |

## 五、制作顺序建议（先做哪个）

1. **先搭设计 Token**（色板+字号+间距）→ 四套共用，保证统一
2. 再画 **模式 A chat_app**（最核心，组件最多，可复用给历史回顾）
3. 然后 **模式 B visual_novel**（A 的气泡组件可复用）
4. 最后 **模式 C / D**（独立性强，量小）
