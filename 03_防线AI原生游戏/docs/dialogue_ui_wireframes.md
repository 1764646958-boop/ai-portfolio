# 对话呈现系统 UI 线框图 ×4 + 历史回顾方案

- **成员**：C
- **周次**：W1（8/10-8/16）交付物
- **用途**：① D 做 UI 风格定稿的交互参考 ② B 做记忆锚点/记忆考古的组件参考 ③ 自己 W2 落地实现依据
- **定位**：这是**线框文字稿**（布局+尺寸+状态+动画标注），最终视觉以 **D 的美术定稿**为准。

---

## 零、通用规范（四套线框共用）

| 项 | 规范 |
|---|---|
| 基准分辨率 | **1920×1080**（PC 竖屏 UI 元素按此定位，用锚点+百分比布局，避免拉伸） |
| 字体 | 正文 20px / 角色名 18px / 选项 20px / AI 消息 18px（具体字体以 D 定稿为准） |
| 动画统一 | 打字机 **50-80ms/字**；按钮悬停 105% 缩放；所有动画用 GPU 加速（transform/opacity），避免重排 |
| 四种状态 | **正常 / 悬停 / 点击 / 禁用** —— 每套线框都要覆盖这四种状态 |
| 与数据对接 | 四种线框对应 A 交付 JSON 的 `mode` 枚举（见 §5） |

## 一、模式 A：AI 聊天 App 风格（`mode: "chat_app"`）

**用途**：与 AI 对话（核心）——"像和一个真实的聊天 AI 对话"

### 布局

```
┌──────────────────────────────────────────────────┐
│ [状态栏]  <AI名字·LLM生成>         ●●● 信号   18px│ ← 顶部 48px 高
├──────────────────────────────────────────────────┤
│                                                  │
│        AI头像   ┌───────────────────────┐        │
│        (圆形)   │  AI 消息气泡(暖橙底)    │        │
│                │  圆角 16px·米白文字     │        │
│                └───────────────────────┘        │
│  ┌───────────────────────┐                      │
│  │ 旧友消息气泡(灰白底)     │      旧友头像       │
│  │ 发送者名可能是 [X]      │      (模糊/剪影)    │
│  └───────────────────────┘                      │
│                                                  │
│  [可选回复气泡1]   [可选回复气泡2]                 │ ← 主人公的回复=可选气泡
│                                                  │
├──────────────────────────────────────────────────┤
│ [输入框………………]  [自由输入]  [发送]  54px高        │ ← 底部
└──────────────────────────────────────────────────┘
```

### 元素与规格

| 元素 | 位置 | 尺寸 | 颜色（参考，以 D 定稿为准） | 动画/状态 |
|---|---|---|---|---|
| 消息气泡（AI） | 靠左（含 AI 头像） | 最大宽 60% | 暖橙底 `#FFB74D`、米白字 `#FFF8E7` | 出现时轻微上浮+淡入 200ms |
| 消息气泡（旧友） | 靠右（含旧友头像） | 最大宽 60% | 灰白底 `#F0F0F0`、深灰字 | 同上；发送者名显示 `[X]` |
| 可选回复气泡 | 底部输入区上方 | 同气泡 | 米白描边、暖橙字 | 悬停 105% / 点击填充暖橙 / 禁用置灰 |
| "自由输入"按钮 | 输入框右侧 | 120×40px | 暖橙描边 | 点击展开键盘输入 |
| "正在输入…"动画 | AI 头像旁 | 三点 | 暖橙 | 三点依次亮灭，周期 1.2s |
| 边缘闪烁 | 屏幕四周 | 1-2 帧 | 极淡蓝光 | AI"处理"痕迹，低频偶发 |

> 关键：AI 界面要"温柔、简洁、被照顾"——参考微信/Telegram 但更克制。

## 二、模式 B：视觉小说式（`mode: "visual_novel"`）

**用途**：与旧友面对面对话——标准视觉小说格式

### 布局

```
┌──────────────────────────────────────────────────┐
│                                                  │
│                                                  │
│              [旧友立绘 · 背影/侧影]                │ ← 屏幕一侧(右/左)
│              (永远无正脸)                         │
│                                                  │
│  ┌────────────────────────────────────────────┐  │
│  │ 旧友                     (名字 18px·加粗)   │  │
│  │ "……" 打字机效果，字幕可短暂"卡顿"          │  │ ← 底部半透明文本框
│  └────────────────────────────────────────────┘  │
│  [选项1]    [选项2]    [选项3]                     │ ← 选项菜单
└──────────────────────────────────────────────────┘
```

### 元素与规格

| 元素 | 位置 | 尺寸 | 颜色 | 动画/状态 |
|---|---|---|---|---|
| 文本框 | 底部 | 高 180px、全宽、左右留白 60px | 半透明黑 `rgba(0,0,0,0.55)`、白字 | 打字机 50-80ms/字 |
| 角色名 | 文本框内左上角 | 18px 加粗 | 暖色（旧友名） | — |
| 立绘预留位 | 屏幕左侧/右侧/中央（**三布局可配**） | 高约 70% 屏 | — | 淡入 300ms |
| 字幕卡顿 | 文本框内 | — | — | **偶发卡顿**：某段文字显示到一半停顿 200-400ms（AI 过滤痕迹） |
| 选项菜单 | 文本框上方 | 20px | 悬停 105% / 选中高亮 | 出现时淡入 150ms |

> 立绘三布局是 W2 硬要求：`chat_app` 用中央，`visual_novel` 用左右侧——同一套对话系统里用 `portrait_position` 参数切换。

## 三、模式 C：全屏侵入式（`mode: "fullscreen"`）

**用途**：战斗中的 AI 对话——"打破第四墙，AI 入侵你的认知空间"

### 布局

```
┌──────────────────────────────────────────────────┐
│▓▓▓▓▓ 冷蓝AI界面边框向内侵蚀 ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│ ← 边缘
│▓ ┌──────────────────────────────────────────┐ ▓│
│▓ │                                          │ ▓│
│▓ │   AI 话语逐字打出，直接浮现在侵蚀区域内    │ ▓│
│▓ │   (无传统对话框)                          │ ▓│
│▓ │                                          │ ▓│
│▓ │   配合耳语音轨 / 心跳 / 白噪音            │ ▓│
│▓ └──────────────────────────────────────────┘ ▓│
│▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│
└──────────────────────────────────────────────────┘
```

### 元素与规格

| 元素 | 位置 | 尺寸 | 颜色 | 动画/状态 |
|---|---|---|---|---|
| AI 话语 | 从屏幕**边缘**浮现，不居中 | 逐字 | 冷白/淡蓝字 | 打字机，逐字 50-80ms；字可轻微抖动 |
| 侵蚀边框 | 屏幕四周 | 由外向内扩张 | 冷蓝 `#2C3E50`→`#4A90D9` | 与 A 的 Shader 侵蚀联动（W4） |
| 无对话框 | — | — | — | 话语直接浮在侵蚀区，无底部文本框 |

> 关键：这一模式**没有传统对话框**，文字是"长在"被侵蚀的画面里的。实现上做一个全屏 CanvasLayer，文字节点挂在侵蚀层下。

## 四、模式 D：记忆卡片式（`mode: "memory_card"`）

**用途**：记忆考古——辨别真假记忆，3 张卡片 3 秒内选择

### 布局

```
┌──────────────────────────────────────────────────┐
│                                                  │
│        ┌──────────┐  ┌──────────┐  ┌──────────┐ │
│        │  卡片1    │  │  卡片2    │  │  卡片3    │ │
│        │ 真实版本   │  │ 假·负面   │  │ 假·微偏    │ │
│        │(暖色残留) │  │(纯冷蓝)   │  │(纯冷蓝)   │ │
│        └──────────┘  └──────────┘  └──────────┘ │
│            [圆形倒计时·绿→黄→红]                   │ ← 3秒
│        (数字键1)    (数字键2)    (数字键3)         │
└──────────────────────────────────────────────────┘
```

### 元素与规格

| 元素 | 位置 | 尺寸 | 颜色 | 动画/状态 |
|---|---|---|---|---|
| 记忆卡片 ×3 | 屏幕中部并排/层叠 | 每张约 360×500px | 真实版暖色残留、假版冷蓝 | 悬停上浮 105% / 选中高亮 / 未选中置灰 |
| 3 秒倒计时 | 卡片上方 | 圆形进度条 | 绿→黄→红渐变 | 从满到空，1 秒内变红 |
| 数字键提示 | 卡片下方 | 18px | 灰 | 按 1/2/3 选择 |
| 纸质感/屏幕纹理 | 卡片背景 | — | 轻微纹理 | — |
| 记忆闪烁 | 全屏 | 1-2 帧 | 白闪 + 电流音 | AI 篡改痕迹（B 实现） |

> 关键线索：**真实碎片有微弱暖色调残留，假碎片为纯冷蓝**——这是玩家辨别真假的隐含视觉线索，线框里必须标出这个冷暖差异。

## 五、对话历史回顾方案

**用途**：让玩家回顾已发生的对话（W2 v0.1 预留入口，W4 完整实现）

### 交互方案

| 项 | 方案 |
|---|---|
| 入口 | 聊天界面上方一个 "回顾" 图标按钮（📜），点击呼出 |
| 呈现 | 半透明黑底浮层 + 滚动列表，复用消息气泡组件（不重写组件） |
| 预加载 | **≥50 条**历史消息预加载，滚动流畅 |
| 滚动 | 虚拟化滚动（Godot `ScrollContainer` + 复用 Item，或 `ItemList`），100 条无卡顿 |
| 搜索/筛选 | W4 加：按角色名筛选 + 关键词搜索（中文分词） |
| 自动定位 | 呼出时默认滚动到最新一条 |

### 状态覆盖

- 正常：列表静止
- 滚动中：拖拽滚动条、滚轮
- 空状态：无历史时显示占位提示
- 搜索无结果：显示"没有找到相关内容"

## 六、与对话数据格式（§6.3 A→C）的映射

A 交付的 JSON 里 `mode` 字段直接决定用哪套 UI：

| `mode` 值 | 线框 | 触发场景 |
|---|---|---|
| `chat_app` | 模式 A：AI 聊天 App | 与 AI 对话、旧友手机消息 |
| `visual_novel` | 模式 B：视觉小说 | 与旧友面对面 |
| `fullscreen` | 模式 C：全屏侵入 | 战斗中的 AI 对话 |
| `memory_card` | 模式 D：记忆卡片 | 记忆考古辨别真假 |

> W2 落地时，对话系统读 JSON → 按 `mode` 切换 CanvasLayer，一套代码跑四种 UI。
