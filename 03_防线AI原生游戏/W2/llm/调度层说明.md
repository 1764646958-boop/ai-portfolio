## 二、三引擎接口（ENGINES 注册表）

| 引擎名 | 输入（build 参数） | 输出 schema | 用途 |
|---|---|---|---|
| `memory_analysis` | template_text, player_emotion, anchor_id | `{drift_direction, magnitude, confidence}` | 记忆锚点分析 → 信任偏移判定 |
| `fake_memory` | real_memory, trust_bias, variant_type | `{variant_text, distortion_note}` | 假记忆变体（记忆考古关卡） |
| `dialogue` | context, npc_character, player_history_summary | `{dialogue_text, warmth, manipulation, helpfulness}` | AI 陪伴者台词 |

统一调用：

```python
from deepseek_client import DeepSeekClient
from engines import run_engine, run_engine_with_fallback

client = DeepSeekClient()
result = run_engine(client, "memory_analysis",
                    template_text="...", player_emotion="有点可爱", anchor_id="CF_CAKE_01")
# result = dict 或 None（全部失败，调用方降级）

# 带预设模板兜底（推荐游戏内使用）：
from pipeline import FALLBACK_ANALYSIS
result = run_engine_with_fallback(client, "memory_analysis", FALLBACK_ANALYSIS, ...)
```

## 三、TrustBias API（给 B 的信任偏移对接说明）

```python
from trust_bias import TrustBias
bias = TrustBias()                    # 起点 0，范围 [-10, +10]
bias.update("ai", 3, 1.0)             # ai→正向 +3.0
bias.value                            # 当前值（只读，隐藏数值）
bias.tendency                         # 'ai'/'human'/'neutral'（调试用）
bias.reset()                          # 新游戏/新玩家重置
```

**给 B**：记忆分析引擎的 `drift_direction/magnitude/confidence` 三字段**不进对话 JSON**（集成决策附则），由调度层累积进 TrustBias；B 的"信任偏移行为触发规则表"直接读 `bias.value` 即可（如：>+3 时 AI 假记忆更隐蔽、人类 NPC 退缩）。

## 五、降级策略（对应《防线》"LLM 超时→缓存+轻量规则"）

1. `retry_chat`：单次调用失败指数退避重试（0.5s/1s），默认 2 次
2. `run_engine`：schema 校验失败或调用异常 → 额外重试 2 次
3. 全部失败 → 返回 `None` + 写日志 `logs/engines.log` → 调用方用预设模板（FALLBACK_*）兜底
4. 游戏内铁律：LLM 调用必须异步（await/线程），绝不阻塞渲染帧

## 六、给 C 的 dialogue 输出说明

`dialogue_text` → 对话 JSON 的 `lines[].text`；`warmth/manipulation/helpfulness` → `lines[].meta`（W3 战斗/压迫系统用，W2 可留空）。详见 `W2/docs/dialogue_json_format.md`（提示词 4 产物，待 C 确认）。
