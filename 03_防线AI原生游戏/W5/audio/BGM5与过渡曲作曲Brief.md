# 第一部分：BGM#5 · 结尾曲

## 1.1 使用场景（触发点）

| 场合 | 触发点 | 说明 |
|---|---|---|
| **主用途** | 全作真结局：结局段落（第三幕收束）→ 片尾字幕 / 制作名单 | 结局**画面**段落仍用 7.3 的冷色变奏收尾（见 §1.7），**片尾字幕切 BGM#5**——「冷结束、暖收束」的先后即"被替代"→"和解"的叙事顺序 |
| **Demo（第一幕）** | ① 片尾字幕 / 演示视频收尾段；② 玩家看完 7.3 悬念、**回到主菜单后**解锁替代 BGM#1 播放 | ⚠️ **不建议在 7.3 黑屏与「你想回复他吗？」之后立即播放**——Demo 的钩子是悬念，暖色解决会当场泄掉它 |
| 备选（若评审要求 Demo 结尾直接播） | 7.3 黑屏淡出后 | 只取本曲 **引子段 8 小节（≈28s）**做"未完成的暖"版本，末尾自然衰减回黑屏——**只给暖，不给解决** |
| 其他 | 结局回顾 / 成就页 / 音乐鉴赏模式 | 完整版播放，可循环 |

## 1.2 情绪定位（成熟版，不是复制版）

一句话：**「同一段旋律，从一个人弹给另一个人听，变成他终于能自己哼出来。」**

与 BGM#1 的情绪递进设计（三段式）：

| 阶段 | 音乐状态 | 情绪语义 |
|---|---|---|
| **安静（引子-呈示）** | 钢琴单声部独白，低音区，留白多 | 一个人待着，还没开口 |
| **敞开（展开-再现）** | 弦乐组接过主旋律，和声变厚变亮（maj7/add9） | 记忆不再只是"他的"，成了"我的" |
| **收束（尾段）** | 乐器逐个退出，回到钢琴单声部，停在 Imaj9 | 释怀，但余韵未散（不写"大团圆终止式"） |

情绪曲线整体为 **pp → mf → p**：进得轻、说得完、走得缓。**全程无打击乐、无高潮爆发点**——高潮靠"声部数量"而非"音量"达成。

## 1.3 音乐参数

| 项 | 规格 | 理由 |
|---|---|---|
| 调性 | **C 大调**（自然音，无离调） | ① BGM#1 是 C/G 大调系，结尾回到**同一基音音名**= "回到最初的房间"；② 7.3 的冷色变奏是同基音的小调化（暖色染冷）——**#5 回到同基音大调 = 染冷→回暖的闭环**；③ 第三幕的 A/G 小调（#3/#4）在此被"解冻"，基音回到 C 有明确的听觉归位感 |
| 速度 | **68 BPM**（4/4），可 ±2 | 落在 60-72 建议区间中上：结尾曲比 BGM#2 的"安详步速"（60-70）多一点**向前的微动力**——释怀不等于静止；同时仍在 #1/#2 的速度家族内，衔接不突兀 |
| 拍号 | **4/4**（与 #1-#4 一致，动机为 4/4 骨架） | 不换拍——换拍会读成"另一首曲子"，破坏同族感 |
| 时长 | **2:21**（≈40 小节 @68 BPM，另加尾音自然衰减 2-3s） | 落在 2:00-2:30 建议区间；40 小节是结构上的整数（8+10+10+8+4，见 §1.5） |
| 循环 | **可循环**：末小节尾音衰减后接回引子第 1 小节（首尾同和弦 Cmaj9，循环处无打击点、无硬切） | 供音乐鉴赏/结局回顾长时间播放；正式片尾播放单次即可 |
| 动态范围 | 峰值 ≤ -3 dBFS；**同一段内动态 ≤ 12 dB**（不做"耳语→轰鸣"） | 与 #1-#4 一致；结尾曲靠织体不靠音量 |

## 1.4 旧友主题动机引用方式（重点：4 个具体改编手法）

**与 BGM#1 动机的关系**：**同一动机的成熟变奏**——音程骨架不变（保持可辨识），但"长大的方式"改变。
动机骨架抽取方法沿用 W3.5 §6：把 `w1_main.mp3` 导入 DAW 取前 8-10 秒，确定中心音高与音程序列，**不另创新动机**。

| # | 手法 | 具体做法 | 情绪语义 |
|---|---|---|---|
| **① 动机长度扩展** | BGM#1 中动机为 **2 小节**单次呈示（+ 短暂重复）；本曲把 2 小节扩展为 **4 小节完整乐句**，句尾追加 **1 小节上行六度"抬头"音** | 「一句话」→「一段能说完的话」 |
| **② 配器递进：钢琴独奏 → 弦乐合奏** | 呈示段仍是钢琴独奏（独白感，同 #1）；展开段**中提琴+大提琴齐奏接过主旋律**，钢琴退为对位/装饰；再现段弦乐全组 + 钢琴高八度加厚 | 从"一个人弹"到"一群人在记得" |
| **③ 和声色彩升级：三和弦 → 大七/加九** | #1 用简单三和弦与 I-V-vi-IV 直白进行；本曲在展开段起加入 **IVmaj7 → V9 → Imaj9** 终止式，动机每次重复换一次和声色彩（maj7 / add9 / sus2 短暂经过） | "成年感"：不再是少年时代的干净，是经历过之后的复杂但温和 |
| **④ 「笨拙」被抚平** | BGM#1 动机的节奏落点**略带不规整**（笨拙感=旧友的性格特征）；本曲**再现段把落点抚平为规整节拍**，但在尾段最后两音**故意弹回原来的不规整落点**（只留一次） | 「他不再笨拙了——但我记得他笨拙的样子」 |

**附加约束（与 6.4 的关系）**：
- 6.4 是「旧友喜欢的歌**突然变调**切入（无预告，1-2 帧）」——全作音乐线索**第一次显性化**；BGM#3/#4 的动机克制原则（不得整段呈示）是为了保住 6.4 的惊喜。
- **BGM#5 无此约束**：它出现在剧情已揭底之后，是**全曲最完整、最温暖的一次动机呈示**——这正是「把 6.4 的惊吓落成一个和解」的兑现。两首不冲突：6.4=变调碎片（1-2 帧），#5=成熟完整版（2:21）。

## 1.5 结构与时间轴（40 小节 @68 BPM，4/4）

| 时间 | 小节 | 段落 | 乐器进出 | 动态 | 内容 |
|---|---|---|---|---|---|
| 0:00-0:28 | 1-8 | **引子** | 钢琴单声部（低音区）＋弦乐**泛音垫**（极轻，pp） | **pp** | 无完整动机；只出现动机骨架的**3 音片段**（每 2 小节 1 次，像"想起来一点"）；留白多 |
| 0:28-1:01 | 9-18 | **旧友主题呈示** | 钢琴独奏（右手主旋律，左手单音根音） | **pp → mp** | 完整 2 小节动机 ×2：第 1 次单音呈示，第 2 次加左手八度；**每句尾留 1 拍空拍** |
| 1:01-1:37 | 19-28 | **展开** | **中提琴+大提琴**接过主旋律；钢琴转对位；弦乐第一小提琴长音铺底 | **mp → mf** | 动机扩展为 **4 小节乐句**（手法①）；和声加入 **maj7 / add9**（手法③） |
| 1:37-2:05 | 29-36 | **成熟再现** | 弦乐全组齐奏 + 钢琴高八度加厚；低音提琴进入 | **mf** （峰值） | 动机完整再现，节奏落点**抚平为规整**（手法④前半）；**IVmaj7 → V9 → Imaj9** 终止式落回 C |
| 2:05-2:21 | 37-40 | **尾段** | 弦乐依次退出（只留第一小提琴长音）；钢琴回到单声部 | **mf → p** | 钢琴只弹动机最后两音，**故意弹回不规整落点**（手法④后半）；停 **Imaj9**（有解决，但大七度留"待续"感） |
| （尾音 2-3s） | — | 衰减/循环点 | 钢琴尾音自然衰减 → 首尾同和弦 **Cmaj9** 接回第 1 小节 | — | 循环处无硬切（见 §1.3 循环项） |

**结构计数**：8（引子）+10（呈示）+10（展开）+8（再现）+4（尾段）= **40 小节 = 2:21** ✅ 与 §1.3 一致。

## 1.7 与 7.3 尾声「BGM#1 冷色变奏」的关系（先后与区分）

| 项 | 7.3 尾声（**已定，不改**） | BGM#5 结尾曲（本 Brief） |
|---|---|---|
| 素材来源 | **BGM#1 原曲的变奏**（同一录音素材染冷处理） | **新作**，引用旧友主题动机（同动机家族） |
| 调性 | 同基音**小调化**（暖色染冷） | 同基音 **C 大调**（回暖） |
| 长度 | 短（跟画面，约 30-60s，停在未解决） | 2:21（完整曲式，有解决） |
| 叙事功能 | **悬念**：「被替代」的暗示；第一幕收束 | **和解**：全作情感落点；结局/片尾 |
| 出现顺序 | **先**（第一幕末 7.3 / 第三幕结局画面的最后一冷） | **后**（片尾字幕起） |
| 听觉衔接 | 尾音停在未解决的不谐和音 | 引子从 **pp 钢琴单音**进入——不接 7.3 的尾音，而是**在静默后重新起一个安静的陈述**（避免"同一曲的延续"误读） |

> 一句话交给剪辑/音频实现：**结局画面用冷色变奏收尾 → 画面渐黑 → 静默 1.5-2s → BGM#5 引子的第一个钢琴音进入**。那 1.5-2s 的静默是两首曲之间唯一的"接缝"，也是叙事上的"深呼吸"。

## 1.8 验收标准（评审用）

1. **与 BGM#1 同族**：盲听列表里 #1 与 #5 放一起，6/10 人以上判定"像同一部作品"（同动机家族、同混音空间、同钢琴/弦乐音色）。
2. **旧友主题可辨识**：不提示的情况下，≥6/10 人能在展开段（1:01 后）指出"这段旋律前面听过"。
3. **暖而不甜**：盲投"这首曲子会不会太煽情"——**≤2/10 人**选"煽情/过头"；无鼓、无大齐奏爆发、无大调终止式的"完成感"堆叠（尾段必须留 Imaj9 的待续感）。
4. **不泄悬念**：Demo 版本若采用 §1.1 备选方案，播放后**不得**让评审感到"第一幕的悬念被解决了"（若评审有此感受 → 退回只用引子 8 小节）。
5. **结构可核**：40 小节 / 68 BPM / 2:21；手法①②③④各可指认（动机 4 小节乐句、弦乐接主旋律、maj7-add9 和声、再现段规整化+尾段回不规整）。
6. **可重建源文件**：保留 DAW 工程或 MIDI 脚本（评审后修订回源改，不修最终导出稿——同 W3.5 §5.5）。
7. **无电子/冷感音色**：全曲不含合成器 pad/颗粒/失真（与第三幕语汇隔离）。

# 第二部分：过渡曲（Chapter Transition）

## 2.1 使用场景

| 场合 | 说明 |
|---|---|
| 场景切换 | 模块之间转场（如模块 2 咖啡店 → 模块 3 街道；模块 4 考古 → 模块 5 战斗**之前**的 1-2 秒缓冲） |
| 章节过渡 / 黑屏过场 | 7.3 黑屏类过场的淡入淡出垫底 |
| 加载 / 就读 | 场景加载期间循环播放，加载完成淡出 |
| **明确不用** | 战斗内（BGM#4 负责）、有台词的剧情节点（会与对白抢耳朵） |

## 2.2 情绪定位

**中性偏暖、不抢戏、可无缝循环**——它是"门框"不是"画"：玩家不该记住它，但两首正片曲之间不能出现真空。
动机**刻意不做完整引用**（只在第 5-6 小节出现动机骨架的 2 音片段，音量藏在弦乐下），保证它不会被当成"剧情曲"。

## 2.3 音乐参数

| 项 | 规格 | 理由 |
|---|---|---|
| 调性 | **C 大调**（与 BGM#5 同调） | 与结尾曲同调便于任意两曲前后衔接；也在 BGM#1/#2 的大调系内 |
| 速度 | **60 BPM**（4/4） | 慢速、无脉动感；比 BGM#5（68）更慢，保证切换时"慢下来"而非"提速" |
| 时长 | **0:32**（8 小节 @60 BPM），循环点在第 8 小节末 | 落在 0:20-0:40 建议区间；8 小节整数便于循环与打点 |
| 循环 | **无缝**：末小节尾音与第 1 小节起音为**同一和弦音（Cmaj9）**，无衰减尾、无渐弱 | 循环点前后 0.1s 波形目检无咔哒（同 W3.5 §4 口径） |
| 动态 | **pp 恒定**，段内动态 ≤ 6 dB | "背景感"的第一层保障 |
| 响度 | 混音时比正片 BGM **低 3-6 dB**（建议取 **-4 dB**，以 BGM#5 为 0 dB 参考） | 第二层保障；若过渡曲播放期间有对白，再由 AudioStreamPlayer 的总线再 ducking **-3 dB** |
| 时长变化 | 提供 **8 小节完整循环版** + **4 小节短版**（切场景用） | 短版 = 前 4 小节 + 末音衰减（**不循环**） |

## 2.4 配器

| 声部 | 说明 |
|---|---|
| 钢琴（单声部） | 右手单一旋律线，**左手不弹**（或仅每 2 小节一个根音）；触键偏软 |
| 轻弦乐 | 大提琴长音铺底（每 4 小节换一次音），音量比钢琴低 2-3 dB |
| 可选 | 无——**不加任何点缀音色**（钟琴/木吉他留给人声与结局曲） |
| 不使用 | 鼓 / 节奏型 / 合成器 pad / 混响过大的空间音效（避免"耳鸣感"与第三幕混淆） |

## 2.5 验收标准

1. **任意衔接不突兀**：把过渡曲分别插在 BGM#1→#2、#2→#3、#3→#4、#4→#5 之间盲听，**每处过渡无"跳戏"感**（评审 4 处全过）。
2. **循环无缝**：连续播放 5 分钟（≈9 个循环）听不出接缝；循环点前后 0.1s 波形目检无咔哒/spike。
3. **背景感成立**：与任意正片 BGM 相比，主观响度低一档（-3~-6 dB 内）；叠在普通话对白上时**不遮挡人声**（对白清晰度主观合格）。
4. **不抢戏**：盲听后 1 小时，评审无法复述过渡曲的旋律（能记住 = 动机引用失败，需再压低/再简化）。
