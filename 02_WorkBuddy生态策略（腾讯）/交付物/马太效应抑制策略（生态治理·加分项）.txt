Normal	马太效应抑制策略
Normal	——WorkBuddy 开放 Agent 生态 · 生态治理（加分项）——
Normal	在不损害长尾创作者可见性的前提下，识别并抑制“头部资产被反复推荐”的马太效应
Normal	摘要
Normal	马太效应的本质是“只利用、不探索”：头部被反复喂，尾部永远饿着，形成一个**放大失衡的自洽闭环**。本策略把“识别—抑制”做成一个**动态闭环**：先监测“马太是否在恶化”，再在分发层用【探索/利用 + 稀缺加权路由 + 重复曝光打散】加以抑制，最后用一组作用信号验证有效性、用护栏指标控制副作用。
Normal	核心机制一句话：把一部分分发给不确定性更高的“达标长尾”作为“试金石”，用平台能承受的代价反哺生态多样性。稀缺度因子作为路由偏好信号，在“合格基础上的最匹配优先”里给长尾一个公平的竞争力。
Normal	一、问题界定：马太效应从哪来，怎么“识别”
Normal	1.1 根源
Normal	• 正反馈放大：任何基于历史行为的排序都会继续强化头部；头部因曝光多而数据多、数据多而更被信任、更被信任而曝光更多。
Normal	• 冷启动死锁：长尾“没数据→不敢推→更没数据”，能力达标也无法进入分发；平台缺少“给未经验证者一次机会”的机制。
Normal	• 评分基于流量：若质量分只依赖调用量 / 评分，则头部即使非当下最优也可能被反复推荐。
Normal	1.2 识别信号（何时判定“马太在恶化”）
Normal	这些识别信号由**规则**持续计算（可枚举阈值、稳定、可审计），一旦越过阈值即触发抑制层。它们不依赖复杂模型，因而可作为“低门槛、可信”的早期预警。
Normal	二、抑制机制：识别 → 动态探索 → 稀缺加权路由 → 打散重复推荐
Normal	2.1 机制总览（分层）
Normal	2.2 在不损害长尾可见性前提下的克制
Normal	本策略**优先保护长尾可见性**：探索预算保证长尾有首次曝光；稀缺加权让“恰好契合某需求”的长尾能公平竞争；打散重复推荐从头部手里“腾”出曝光位而非削减总量。它不“拉低头部”，而是**给长尾一个对等的起跑线**——因此不会以牺牲长尾为代价来抑制头部。
Normal	三、核心机制：Explore / Exploit + 稀缺偏好
Normal	在 P2 阶段⑥，对每个候选计算“路由分”，权衡“利用已知最优”与“探索未知长尾”：
Normal	score_路由 = Q̂ + β · √(ln t / N)
最终分发 = score_路由 · (1 + α·(稀缺度 × 需求缺口))，α 封顶
Normal	四、作用信号（怎么判定策略起作用）
Normal	“起作用”必须由**可观测、可对照**的信号判定，而非主观感受：
Normal	判定逻辑：**上述信号需联合看**，且必须结合护栏指标一起下结论——若长尾覆盖率上升但满意度/头部体验退化，说明探索过度，应回调 β 与预算。
Normal	五、副作用与护栏（不损害长尾、不过度伤体验）
Normal	六、自适应闭环与策略退出
Normal	策略是**动态闭环**而非一次性开关：
Normal	• 识别→抑制→验证→护栏：用检测层识别信号监测马太状态；用探索/稀缺/打散抑制；用作用信号判定有效；用护栏指标控制副作用。
Normal	• 策略退出：当生态多样性达到稳态目标、长尾覆盖达标后，逐步**回调** β 与探索预算，让策略从“强干预”过渡到“轻维持”，避免长期过度探索。
Normal	• 与 P4 联动：整套策略本身也要接受 P4 的口径切换，保证评估口径与干预强度联动。
Normal	6.1 与各产出物的关系
Normal	七、结论
Normal	本策略以“检测—探索—稀缺加权—打散重复—稀缺豁免”五层机制，在不损害长尾创作者可见性的前提下抑制头部被反复推荐的马太效应；以探索池长尾命中/续用率、生态多样性 Gini、头部份额、头部重复推荐率等**作用信号**判定其是否有效；并以采纳率/满意度/头部体验不退化等**护栏指标**控制过度探索、稀缺滥用等副作用，兼顾“救活长尾”与“不伤体验”这对张力。
