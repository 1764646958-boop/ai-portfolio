## 一句话

平台上的长尾 Agent 资产（低频、少调用、缺评测证据）会被"按调用量排序"永久埋掉。
本方案不用语义相似度、而用**框架信号**判断资产质量与分发资格，并用**离线回溯脚本**标定常数 —— 参数不拍脑袋，seed 固定、结果可复现。

四个阶段各由最合适的判断者承担：**模型 / 规则 / 人，各司其职**。

## 常数是怎么标定的（而不是拍脑袋）

`p1_backtest.py` 用**带真值的合成日志**做离线回溯，分别标定两个常数：

- **β** —— 用 UCB 在历史回流上重放，权衡「平均质量收益」与「长尾获得机会数 / regret（与"总挑真最优"的期望差距）」
- **α** —— 用「稀缺增益」重算分发，看「生态多样性（Gini）」抬升与「命中质量」损失的**拐点**

> 脚本会打印完整对比表；**上面的数字一律以脚本实际输出为准**，本 README 不写死结论值。
