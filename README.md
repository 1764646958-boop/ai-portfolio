## ① 商品智能导购 Agent（澄初个护）

> **LLM 只做翻译，代码做决策。**

- **业务问题**：顾客说不清需求、怕被施压；门店要转化又要守广告法 / 功效宣称 / 医疗边界；品牌手册未提供的信息（促销 / 线上价 / 退换 / 授权）不得编造。
- **架构**：状态机 + 三大门控（敏感 / 政策 / 注入）先于生成；推荐与报价由确定性规则 + 知识库决定；
  **所有外发金额必须等于事实价或事实价之和**（子集和校验，如 `388 = P101 + P203`）；红线场景走硬模板、不调用模型。
- **评测**：`tests/test_scenarios.py`（16 个场景）+ `tests/test_bc.py`（10 条可检查行为 BC-1~10）全部通过；断网 / 无 API key 仍可完整运行。
- **运行**：

```bash
cd 01_商品智能导购Agent（FDE08）
python tests/test_scenarios.py   # 16 场景
python tests/test_bc.py          # BC-1~10
pip install -r requirements.txt
python -m uvicorn server:app --port 8000   # 或双击 start_demo.bat（含公网隧道）
```

**结构**：`rules.py`（确定性规则层）/ `brand_kb.py`（单一事实源）/ `nl.py`（LLM 翻译层 + 价格白名单校验）/ `agent.py`（编排）/ `server.py`（FastAPI 入口）/ `文档/`（复盘、演示脚本、SOP）

## ② WorkBuddy 开放 Agent 生态 · 资产质量与分发策略

> **让达标长尾资产有资格被看见。**

- **业务问题**：自然语言描述需求后连续 3 次匹配失败即放弃；仅 8% 创作者两周内获超 100 次调用；头部虹吸形成冷启动死锁。
- **分工第一性原理**：语义归模型、确定性归规则、不可逆决策归人。
- **交付物**：质量评估框架（双因子 + 双轨评分 + 贝叶斯收缩 + 三层门禁 + 五支柱采信）、10 阶段分发链路、可交互原型、效果指标与口径切换方案、马太效应抑制策略（加分项）。
- **验证**：原型内置「传统排序 vs 本框架」对照 —— 长尾需求「清蒸鲈鱼配什么清酒」按调用量排序命中 51,200 次调用的头部（几乎零契合），本框架命中仅 84 次调用的长尾；
  常数 `k / β / α` 由离线回溯脚本标定（`seed` 固定、可复现）。
- **运行**：双击 `可交互原型/index.html`（零安装，可切换真实 LLM）；校准脚本 `实现与校准/p1_backtest.py`。

## ⑥ XGBoost 出品时间预测

- 171 万条训练样本（时序划分）、24 个特征、308 家门店；排队特征用事件驱动算法 `O(N log N)` 精确计算。
- 外部测试集 **MAE 3.27 分钟 / RMSE 4.93 / R² 0.6901**，误差 ≤5 分钟覆盖 81% 订单；预订单独立建模使 MAE 30.92 → 9.90（-68%）。
- 商业判断：门店偏差校准 + P35 保守偏移（+1.1min，capped@3min），宁可高估也不让顾客等更久。

## ⑦ CloudLoom · 团队 AI 协作工作台（原「方案C」）

> **让 3 人工作室拥有一位"数字员工办公室"：入口唯一、零件可换、每次协作都沉淀成团队记忆。**

- **业务问题**：AI 用得散（每次重讲背景）、任务没容器（谁在做什么靠人记）、团队记忆留不住（群里定的决策过几天找不到）。
- **架构**：单页工作台 7 Tab（聊天 / 看板 / 任务 / 画像 / 资料库 / 记忆 / 设置）+ 自研代理层（兼 MCP 网关）+ 4 个常驻 Agent（仅绑 localhost）+ **自建 Agent 懒启动**（空闲 30 分钟自动停机，实测 wake 0.2s / ready 4.3s）+ SQLite 记忆库（FTS5 + `private/team/restricted` 可见性）。
- **护栏**：涉金额 / 对外承诺 / 删数据三类任务**强制人审**；审批动作落库形成"**成员改了什么，Agent 记住**"的反馈闭环；每个 Agent 显式定义"可自主 / 需人审 / 禁止"三清单 + 失败兜底；产物带 `MANIFEST.json`（sha256）校验；重启恢复"可见 + 不覆盖"。
- **评测**：19 项端到端验收（17 项通过，2 项环境性延期并显式标注、不以"已知问题"蒙混）+ 真实浏览器 **42 项断言**每批回归 + **5 轮"不上自述、直接实测"的独立复核**（关键项亲手重现：第二实例闸门、30 分钟停机、看门狗实弹告警、0-token 快照、用量记账）。
- **成本治理**：定时 LLM 作业 **15 次/周 → 1 次/周（−93.3%）**、预计花费 **−94.5%**（一次周报实测 ≈¥0.069）；新增**每日 0-token 脚本快照**、**用量台账**、**长会话上下文瘦身**。
- **角色边界**：我负责**规格 / 技术决策 / 验收标准 / 独立复核**；**代码实现由 AI 编码代理完成**（Kimi Code → 限额后切换 Claude Code，本机运行 + SSH 远程）——"人定规格与验收 → AI 执行 → 人独立复核"这套方法本身就是本作品的展示重点。
