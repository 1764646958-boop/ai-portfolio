## 三、核心设计一句话

> **LLM 只做翻译，代码做决策。** 推荐谁、价格多少、合不合规、要不要升级，全由确定性规则层
> （`rules.py`）决定并绑定**价格白名单子集和校验**；LLM 只在非红线态做「理解意图 + 把话说自然」，
> 其任何产出都要过 `validate_prices`，违规回退硬模板。

## 四、已验证（本包自测）

- 离线 16 场景：**全部通过 ✅**
- BC-1~10：**全部通过 ✅**（含 388 = P101+P203 子集和价格、无 P301 泄漏、追问 ≤2、注入拒绝）

- 无 key 在线：`/api/chat` 正常回退到确定性事实句，不抛错。

## 五、如何让我更出彩（面试加分点）

1. **信任主线**明说：目标 = 顾客需求匹配 + 预算匹配 + 信任，**不是推贵 / 连带 / 利润**。
2. **红线前置**：8% 果酸 P201 = 敏感边界核弹，敏感/没经验直接拒绝而非「先推销再说」。
3. **可复现性**：价格永远是「事实价 ∪ 子集和」，不是 LLM 嘴里的随机数。
4. **离线兜底**：现场没网 / 没 key 也能完整演，这个「抗风险设计」本身就是亮点。
